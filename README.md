# CityManager 2.1

เกมสร้างเมือง 3D บนเว็บ เขียนใหม่ด้วย **PlayCanvas Engine + TypeScript** ได้แรงบันดาลใจด้านการเล่นจาก Cities: Skylines II จุดเด่นคือ **เศรษฐกิจที่อธิบายได้**: เงินทุกบาทเป็นสตางค์จำนวนเต็มที่มีบัญชีคู่ สินค้าและพืชผลทุกหน่วยมีที่มาที่ไป และทุกอาคารบอกได้ว่าทำไมจึงเติบโต หยุด หรือขาดอะไร

**[เล่น CityManager](https://nustanakritwithai.github.io/CityManager/)** · เล่นได้ทั้งเดสก์ท็อปและมือถือ · เซฟอยู่ในเบราว์เซอร์ของคุณ

## เป้าหมาย
พาเมืองผ่าน 5 ระดับ ป้ายระดับใต้ชื่อเกมบอกว่าต้องทำอะไรต่อ ([รายละเอียด](docs/GOALS.th.md))

1. **หมู่บ้าน**: มีครัวเรือนย้ายเข้าบ้าน
2. **ชุมชน**: ฟาร์มเก็บเกี่ยว และโรงงานแปรรูปพืชผล
3. **เมืองเล็ก**: ร้านค้าขายสินค้าที่โรงงานในเมืองผลิต
4. **เมือง**: ประชากร 20 คนขึ้นไป และแรงงานมีงาน 80% ขึ้นไป
5. **เมืองพึ่งพาตนเองได้ (ชนะ)**: ไม่นำเข้าสินค้า 30 วัน ขายสินค้าในเมือง 150 หน่วยใน 30 วัน และเงินคลังเพิ่มขึ้น 3 เดือนติดกัน

เมืองที่เล่นดีชนะในราว 9–13 เดือนของเวลาในเกม ชนะแล้วเล่นต่อแบบอิสระได้

## วิธีเล่น
เกมเริ่มจากแผนที่ว่างที่มีแค่ประตูเมือง **ผู้ช่วยสอน** การ์ดเหนือแถบเครื่องมือพาสร้างทีละขั้น 9 ขั้น (ถนน → บ้าน → ฟาร์ม → โรงงาน → พาณิชย์ → กดเล่น → ห่วงโซ่สินค้า → ขยายเมือง → โรงไฟฟ้าและโรงสูบน้ำ) ปุ่มบนการ์ดเลือกเครื่องมือให้ กด "ข้าม" ได้ทุกเมื่อ อยากได้เมืองที่มีถนนและโซนให้แล้ว เลือก **เมืองตัวอย่าง** ในเมนูเกม → เริ่มใหม่ (หรือเปิดด้วย `?starter=1`)

1. ต่อถนนจากประตูสีทองฝั่งตะวันตก ทุกโซนต้องติดถนนที่เชื่อมถึงประตู
2. วางโซน **บ้าน (R) / พาณิชย์ (C) / โรงงาน (I) / ฟาร์ม (F)** อาคารเกิดเองเมื่อมีถนน น้ำไฟ ความต้องการ และค่าเช่าที่จ่ายไหว ฟาร์มวางได้ทุกระดับดิน และแตะฟาร์มเพื่อเลือกพืชได้หลังสร้างเสร็จ
3. เมืองโตเกินราว 16 คน น้ำไฟจากประตูเมืองจะไม่พอ สร้าง **โรงไฟฟ้า (5)** และ **โรงสูบน้ำ (6)** บนแปลงว่างริมถนน
4. กดเล่น (Space) แล้วดูเมืองโต ปุ่ม 1× / 3× / 10× เร่งเวลา หนึ่งวันในเกมคือหนึ่ง tick และ 30 วันต่อเดือน
5. แตะอาคารเพื่อดูการ์ดของอาคารนั้น ป้าย ! เหนืออาคารบอกปัญหา เช่น ไม่มีแรงงาน ขาดวัตถุดิบ ต้องนำเข้า หรือเงินกิจการหมด
6. **ภาพรวมเมือง** มีเป้าหมาย การเงิน ห่วงโซ่สินค้า และบัญชีทั้งเมือง **สถิติ (T)** **เครือข่ายเมือง (N)** และ **แผนที่ (M)** ช่วยดูภาพใหญ่
7. **เมนูเกม** มีบันทึก โหลด นำเข้าเซฟรุ่นเก่า เริ่มเมืองใหม่ และสวิตช์ฟีเจอร์ทดลอง

## ระบบในเกม
- **น้ำและไฟ**: ประตูเมืองจ่ายได้อย่างละ 20 หน่วย โรงไฟฟ้าและโรงสูบน้ำเพิ่มโรงละ 40 หน่วย น้ำไฟวิ่งตามถนน ถ้าไม่พอ อาคารที่ไกลแหล่งจ่ายที่สุดขาดก่อนและหยุดทำงาน ครัวเรือนและกิจการจ่ายค่าน้ำไฟให้เมืองทุกเดือน ([น้ำและไฟ](docs/UTILITIES.th.md))
- **ภารกิจเสริม**: เพิ่มฟาร์มและโรงงานให้ครบ 3 สาย แล้วให้ครัวเรือนซื้อสินค้าครบ 3 ประเภทภายใน 30 วัน ดูความคืบหน้าในภาพรวมเมือง โดยไม่กระทบเซฟหรือเงินคลัง ([รายละเอียด](docs/SIDE-MISSIONS.th.md))
- **สินค้า 3 สาย**: ฟาร์มเลือกพืชอัตโนมัติตอนเปิด โดยเลือกชนิดที่มีฟาร์มน้อยที่สุด ผู้เล่นเปลี่ยนเป็นข้าว ผัก หรืออ้อยได้ โรงงานเลือกสูตรอัตโนมัติหรือเลือกเองได้ (โรงสีข้าว โรงงานอาหารกระป๋อง โรงงานน้ำตาล) ร้านค้าขายข้าวสาร อาหารกระป๋อง น้ำตาล ครัวเรือนซื้อคละกัน ([สินค้า](docs/GOODS.th.md))
- **ห่วงโซ่สินค้า**: ฟาร์ม → ตลาด/โรงงาน → ร้านค้า → ครัวเรือน → ภาษี → คลังเมือง ([ร้านค้า](docs/RETAIL.th.md), [เกษตร](docs/AGRICULTURE.md), [สมดุล](docs/BALANCE.th.md))
- **อาหาร**: สมาชิกแต่ละคนต้องการวันละหนึ่งหน่วย ครัวเรือนจ่ายจากเงินร่วม ซื้อพืชผลจากตลาดหรือสินค้าสำเร็จรูปจากร้านเท่าที่เงินและของมี การ์ดครัวเรือนแสดงยอดที่ซื้อและขาดในวันนั้น
- **ครัวเรือนและแรงงาน**: สมาชิก ทักษะ งานหลายแห่ง ค่าจ้างตามวันทำงานจริง ย้ายเข้าเมื่อมีงานว่าง แรงงานเฉพาะทางเปลี่ยนอาชีพเมื่อสายงานเดิมไม่มีตำแหน่ง ครัวเรือนที่ไม่มีงาน 2 เดือนย้ายออกพร้อมเงินออม ([ครัวเรือน](docs/HOUSEHOLDS.md), [แรงงาน](docs/LABOR.md), [สมดุลประชากร](docs/BALANCE.th.md#ประชากรและแรงงาน-12))
- **การเติบโต**: ฟาร์มส่งออกพืชผลส่วนเกินผ่านประตูเมือง เมื่อเมืองมีคน 20 คนขึ้นไปและส่งออกพืชผลมากพอ ผู้ลงทุนภายนอกเปิดโรงงานใหม่ในแปลงที่วางไว้ (เดือนละไม่เกิน 1 แห่ง) งานว่างบน HUD นับเฉพาะตำแหน่งที่จ่ายค่าจ้างได้ ([สมดุลการเติบโต](docs/BALANCE.th.md#จังหวะการเติบโต-13))
- **กิจการ**: ตลาดและร้านค้าของครัวเรือน (ใช้เงินออมและแรงงานเจ้าของ) ร้านค้าจากทุนภายนอก โรงงานที่ขยายด้วยกำไรของตัวเอง ฟาร์มระดับ 1–3 และตลาดที่มีกำไรยกระดับเป็นร้านค้า ([การเติบโต](docs/GROWTH.md))
- **โรงงานรอวัตถุดิบ**: หากโรงงานปิดเพราะหมดเงิน ผู้ลงทุนจะรับช่วงเมื่อมีฟาร์มหรือตลาดที่เข้าถึงได้และมีพืชตรงสูตรหรือฟาร์มที่กำลังปลูกพืชนั้น โรงงานเลือกสูตรที่มีวัตถุดิบรองรับ และตรวจใหม่ทุกเดือนเมื่อขาดของ
- **รายได้เจ้าของกิจการ**: สิ้นเดือนกิจการกันกำไรสุทธิหลังภาษี 25% ไว้พัฒนาธุรกิจ และจ่ายส่วนที่เหลือให้เจ้าของตลาดหรือร้านค้าตามกำไรและเงินที่ถอนได้จริง โดยรักษาเงินทุนหมุนเวียน หากขาดทุนหรือเงินไม่พอจะได้รับน้อยลงหรือไม่ได้รับ เงินสะสมอยู่ในบัญชีกิจการและใช้ดำเนินงานหรือขยายกิจการได้
- **ภาพเมือง**: เวลาในวัน ฤดูกาล ฝน ไฟกลางคืน รถ คนเดิน และควันโรงงาน เป็นภาพตกแต่งจากจำนวนจริงของวันนั้น ไม่ใช่การจำลองรายคัน ([บรรยากาศ](docs/ATMOSPHERE.md))

## เสียง
เสียงปุ่ม เสียงเหตุการณ์ในเมือง เสียงบรรยากาศ (ฝน ลม นก จิ้งหรีด โรงงาน) และเพลง CC0 สามเพลง ปรับในเมนูบรรยากาศ ☀ หรือกด **U** ปิด/เปิดเสียง เสียงเริ่มหลังแตะหน้าจอครั้งแรก ([รายละเอียด](docs/AUDIO.th.md))

## ฟีเจอร์ทดลอง (ปิดไว้ก่อน)
สัญญาณเมือง คำถามเชิงข้อมูล คำอธิบายจาก AI และ Typhoon ผู้ช่วยเจ้าของตลาด อยู่หลังสวิตช์ในเมนูเกม (หรือ `?advanced=1` สำหรับครั้งเดียว) บางส่วนเชื่อมต่อเซิร์ฟเวอร์ภายนอกเมื่อเปิดใช้ ([สัญญาณ](docs/SIGNALS.md), [คำอธิบาย](docs/ENTITY-EXPLANATION-ACTIVATION.md), [Typhoon](docs/OWNER-DECISIONS.md))

## เซฟ
เซฟเมืองที่มีระบบการศึกษาใช้ **v22 / `chain-17`**; เมื่อมีกิจการเกิน 64 แห่ง จะใช้ **v23 / `chain-18`** และเก็บสำเนาเซฟเดิมก่อนบันทึกทับ แผนที่ยังจำกัดอาคารรวมบ้านและกิจการที่ 192 แห่ง ไม่ใช่กิจการไม่จำกัด เซฟเดิมยังโหลดได้ การเปิดเซฟไม่เขียนทับต้นฉบับ และข้อมูล Guest/บัญชี/สินค้าเดิมไม่ถูกสร้างใหม่ ([ขอบเขตและการกู้คืน](docs/BUSINESS-CAPACITY.md))

ทุกเวอร์ชันปัจจุบันยังใช้ช่อง `citymanager.save.v7` เซฟ v1–v6 นำเข้าแบบอ่านอย่างเดียวและเก็บสำเนาต้นฉบับก่อนบันทึก

## ข้อจำกัดที่ยอมรับในรุ่น 1.0
- แผนที่ราบ 24×24 ช่อง ถนนกริด
- น้ำและไฟมาจากนอกเมืองทุกแปลง ยังไม่มีเครือข่ายหรือกำลังผลิต
- อัตราภาษี (ค่าจ้าง 10% กำไร 20%) และราคาสินค้าตั้งตายตัว ผู้เล่นยังปรับนโยบายไม่ได้
- ยังไม่มีบริการเมือง (โรงเรียน คลินิก สวน) หรือเหตุการณ์สุ่ม
- รถและคนเดินเป็นภาพตกแต่ง ไม่ใช่การจำลองรายคัน/รายคน
- เซฟอยู่ใน localStorage ของเบราว์เซอร์เดียว เมืองยาวมาก (ราว 900 วันขึ้นไป) อาจเกินโควตา

สิ่งที่วางแผนไว้หลัง 1.0 อยู่ใน [POST-1.0.th.md](docs/POST-1.0.th.md) ประวัติการเปลี่ยนแปลงอยู่ใน [CHANGELOG.md](CHANGELOG.md)

## รันในเครื่องและทดสอบ

ใช้ Node.js 24 และ npm โดย dependency ถูกล็อกใน `package-lock.json`:

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงภายใต้ `/CityManager/` ตรวจหน่วยจำลอง ไฟล์ asset และ production build:

```sh
npm test
npm run test:advisor
npm run assets:verify
npm run build
npm run preview
```

เปิด preview ที่ port 4173 แล้วรัน browser suites ในอีก terminal โดยใช้ Microsoft Edge ที่ติดตั้งอยู่ สคริปต์แยก profile และรายงานไว้ใน `.test-output/` ไม่ดาวน์โหลด browser:

```sh
npm run test:browser
npm run test:submenus
npm run test:context
npm run test:compact
npm run test:population
npm run test:worker
npm run test:agriculture
npm run test:building-cards
npm run test:audio
```

กำหนด `CITYMANAGER_BROWSER` ได้หากต้องระบุ executable เอง และตั้ง `CITYMANAGER_BLOCK_MODELS=1` เพื่อทวนชุดเดิมในกรณีโมเดลโหลดไม่ได้ การตรวจหน้าสัญญาณใช้ build แยกและ mock/offline ตาม [Signals](docs/SIGNALS.md) โดยไม่เปลี่ยน production `dist/` หรือเรียกผู้ให้บริการระหว่าง QA ผลผ่านต้องอ้างถึง source commit และ CI ของ PR จริง การจำลอง viewport/touch ไม่ใช่การทดสอบ Galaxy S22 เครื่องจริง

## เครดิตและเผยแพร่

โมเดลเมืองและไอคอนใช้ Kenney CC0 พร้อมรูปทรงและพื้นดินที่สร้างเอง ฟอนต์ IBM Plex Sans Thai (OFL 1.1) ฝังมากับเกม ดูหลักการแผงข้อมูลที่ [Panels](docs/PANELS.th.md) มี procedural fallback เมื่อโหลดโมเดลไม่ได้: [Assets](docs/ASSETS.md), [GUI assets](docs/GUI-ASSETS.md), [Terrain](docs/TERRAIN.md) ขอบเขตเดิมอ่านได้ที่ [Design](docs/DESIGN.md) และ [แผนภาษาไทย](docs/PLAN.th.md); สถานะเฉพาะรุ่นให้ยึดเอกสารรุ่นและ PR ล่าสุด

`dist/` ใช้ base `/CityManager/` สำหรับ GitHub Pages การ build ในเครื่องยังไม่ใช่การเผยแพร่ PR ต้องผ่าน simulation tests, TypeScript/build และ Edge acceptance ของ source commit นั้นก่อน Merge จากนั้น workflow บน `main` ตรวจและเผยแพร่ tested artifact ตรวจผลล่าสุดได้จาก [GitHub Actions](https://github.com/nustanakritwithai/CityManager/actions) และต้องตรวจเว็บจริงก่อนรายงานว่าเผยแพร่สำเร็จ

อ้างอิง API: [PlayCanvas standalone](https://developer.playcanvas.com/user-manual/engine/standalone/), [AppBase](https://api.playcanvas.com/engine/classes/AppBase.html), [CameraComponent](https://api.playcanvas.com/engine/classes/CameraComponent.html)
