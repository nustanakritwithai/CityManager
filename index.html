    ยอดกระเป๋าเงิน ทุกบัญชี
    วิธีเล่น อ่านเพิ่มเติม
    1. ต่อถนนจากประตูสีเหลืองฝั่งตะวันตก
    2. วางโซนบ้าน พาณิชย์ ฟาร์ม หรือโรงงานข้างถนนที่เชื่อมถึงประตู
    3. อาคารเกิดเองเมื่อผ่านเงื่อนไข ถนน น้ำ ไฟ ความต้องการ และค่าเช่าที่จ่ายไหว
    4. เป้าหมาย: พาเมืองผ่าน 5 ระดับ หมู่บ้าน → ชุมชน → เมืองเล็ก → เมือง → เมืองพึ่งพาตนเองได้ (ไม่ต้องนำเข้าสินค้า 30 วัน และเงินคลังเพิ่มขึ้น 3 เดือนติดกัน) แตะป้ายระดับใต้ชื่อเกมเพื่อดูสิ่งที่ต้องทำต่อ ชนะแล้วเล่นต่อได้

    ถนน: ลากเส้น หรือแตะจุดเริ่ม–จุดจบรูป L • ปุ่มกลับ / Esc ยกเลิกจุดเริ่ม กดอีกครั้งเพื่อกลับเครื่องมือเลือก

    เมื่อเลือกเครื่องมือ แผนที่จะแสดงชั้นสีที่เกี่ยวข้อง: ถนน = การเชื่อมประตูเมือง, บ้าน = ที่ว่างรับครัวเรือน, พาณิชย์/โรงงาน = แปลงพร้อมเกิด, ฟาร์ม = ความอุดมสมบูรณ์ กรอบเขียวคือวางได้ กรอบแดงคือระบบจะปฏิเสธ พร้อมป้ายราคาหรือเหตุผล ไอคอน ! เหนืออาคารบอกปัญหา แตะอาคารเพื่อดูรายละเอียด

    ลากด้วย Pan เพื่อเลื่อน • ลากปุ่มขวาเพื่อหมุน • ล้อเมาส์หรือบีบนิ้วเพื่อซูม • ใช้ปุ่มกล้องได้เช่นกัน

    สมมติฐานต้นแบบ ขอบเขต

    น้ำและไฟมาจากภายนอกทุกแปลง ยังไม่มีเครือข่ายหรือข้อจำกัดกำลังผลิต

    โรงงานแรกเริ่มได้โดยยังไม่มีคนงาน และสองครัวเรือนแรกย้ายเข้าได้โดยยังไม่มีงาน ทุนเริ่มร้านค้า โรงงาน และฟาร์ม รวมทั้งเงินออมผู้ย้ายเข้ามาจากบัญชีภายนอก ส่วนพาณิชย์ใหม่เริ่มเป็นตลาดระดับ 1 ใช้เงินและแรงงานของครัวเรือนเจ้าของ ร้านค้าเปิดเมื่อโรงงานมีคนงาน โดยครัวเรือนที่มีเงินออมเป็นเจ้าของเองหรือใช้ทุนภายนอก ฟาร์มขยายได้ถึงระดับ 3 และตลาดที่มีกำไรยกระดับเป็นร้านค้าได้เมื่อเมืองต้องการร้านเพิ่ม กระเป๋ากิจการแยกจากเงินส่วนตัว ตรวจสอบได้ในรายการเงิน

    รถ รถบรรทุก คนเดิน และควันโรงงานบนแผนที่เป็นภาพตกแต่ง จำนวนอิงข้อมูลจริงของวันนั้น (คนที่ได้งาน ผู้อยู่อาศัย การส่งสินค้า และโรงงานที่ผลิตจริง) แต่ไม่ใช่การจำลองรถหรือคนรายตัว ปิดได้ในเมนูบรรยากาศ ☀ และปิดเองในคุณภาพต่ำ
