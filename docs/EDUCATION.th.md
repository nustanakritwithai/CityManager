# การศึกษา: โรงเรียน มหาวิทยาลัย และเงื่อนไขอัปเกรด

ฐานโค้ด: `c6c11328826b6f204c9a2aee97305e9c3107b369` (main หลัง PR #77 ความจุประชากร) ไม่มี pull request ที่เปิดอยู่ตอนตรวจ

## ระบบเดิมที่ตรวจแล้ว

- ครัวเรือนเก็บจำนวนคน: `members = workforce + dependents` ครอบครัวที่ย้ายเข้าคือ 3 คน = แรงงาน 2 + ผู้พึ่งพิง 1 ไม่มีอายุรายบุคคล
- `workerSkills` เป็นทักษะอาชีพ `general` / `manufacturing` / `retail` รวมเท่ากับกำลังแรงงาน ไม่ใช่วุฒิการศึกษา
- การจ้างใช้จำนวนคนที่เหลือหลังหักเจ้าของกิจการและสวน ไม่มีตัวละครรายคน
- ที่อยู่อาศัยระดับ 1–3 เป็นบ้าน ระดับ 4–6 เป็นอพาร์ตเมนต์ ระดับ 7–9 เป็นคอนโด โรงงาน 9 ระดับ ร้าน 7 ระดับ ฟาร์มมีระดับของตัวเอง
- การอัปเกรดรายเดือนเดิมดูอายุ ถนน น้ำ ไฟ กำไร เงิน และคนทำงาน
- เซฟปัจจุบันคือ v19 `chain-14`, v20 `chain-15` เมื่อมีโครงถนน, หรือ v21 `chain-16` เมื่อมี `populationCapacityVersion`
- ไม่พบระบบโรงเรียน ผู้เรียน หรือวุฒิใน main ก่อนงานนี้

## สมมติฐาน

- ผู้มีสิทธิ์เรียนคือกำลังแรงงานที่ยังไม่มีวุฒิขั้นนั้น ไม่นับผู้พึ่งพิงเป็นนักเรียน เพราะไม่มีอายุยืนยันว่าเป็นเด็ก
- ครัวเรือนที่มีแรงงานมากกว่า 1 คนต้องเหลืออย่างน้อย 1 คนที่ไม่ใช่ผู้เรียน
- คนที่เรียนหรือสอนถูกกันออกจากงานอื่นทั้งวัน เพราะโมเดลไม่มีชั่วโมงย่อย การกันนี้ทำให้คนเดียวกันไม่ถูกนับสองงาน
- คุณวุฒิพื้นฐานได้จากโรงเรียน คุณวุฒิขั้นสูงได้จากมหาวิทยาลัยและต้องมีวุฒิพื้นฐานอยู่แล้ว
- ครูท้องถิ่นต้องมีวุฒิพื้นฐาน อาจารย์ท้องถิ่นต้องมีวุฒิขั้นสูง
- เมืองใหม่ยังไม่มีผู้จบ จึงมีครูสัญญาจากภายนอกได้ไม่เกิน 2 คน และอาจารย์สัญญาได้ 1 คน จ่ายจากคลังไปบัญชี `outside` ไม่สร้างประชากร
- เมื่อมีบุคลากรในเมืองพอ สัญญาภายนอกของแห่งนั้นหยุด
- ขาดถนน น้ำ ไฟ งบ หรือกดพักบริการแล้วความก้าวหน้าหยุด วุฒิที่ได้แล้วไม่ถูกลบ
- รื้อสถานศึกษาถอนผู้เรียนที่ยังไม่จบและจ่ายค่าจ้างที่ทำไปแล้ว
- อาคารที่สูงอยู่แล้วไม่ถูกลดระดับ เกณฑ์การศึกษาใช้กับการอัปเกรดครั้งถัดไปเท่านั้น และยังไม่ลดกำลังผลิตของอาคารเดิม
- ตัวเลขด้านล่างเป็นค่าตั้งต้นที่ปรับได้ ไม่ใช่ค่าที่ผู้ใช้อนุมัติแล้ว

## ค่าตั้งต้น

| รายการ | โรงเรียน | มหาวิทยาลัย |
| --- | --- | --- |
| ค่าก่อสร้าง | 2,000 เครดิต | 4,000 เครดิต |
| ค่าขยายระดับ 2 | 1,500 | 2,500 |
| ที่เรียนระดับ 1 / 2 | 8 / 16 | 4 / 8 |
| บุคลากรที่ต้องการ | 1 / 2 | 1 / 2 |
| วันเรียนจนจบ | 60 | 90 |
| ค่าจ้างคนในเมืองต่อวัน | 14 เครดิต | 20 เครดิต |
| ค่าสัญญาภายนอกต่อวัน | 20 เครดิต | 28 เครดิต |
| ไฟ/น้ำระดับ 1 | 1 / 1 | 2 / 1 |

ที่เรียนที่ใช้ได้เป็นศูนย์เมื่อไม่มีถนนที่เชื่อมเมือง น้ำหรือไฟสำรองไม่พอ งบไม่พอ หรือพักบริการ

## เกณฑ์อัปเกรดครั้งถัดไป เมื่อเปิดระบบ

| อาคาร | ระดับถัดไปที่ยังเหมือนเดิม | ระดับที่เพิ่มเงื่อนไข |
| --- | --- | --- |
| ที่อยู่ | 1–3 บ้าน | 4–6 ต้องมีโรงเรียนที่ให้บริการสะสมครบ 30 วัน วันที่โรงเรียนหยุดจะพักตัวนับไว้ไม่เริ่มใหม่ และมีผู้ถือวุฒิพื้นฐานในเมือง 7–9 ใช้มหาวิทยาลัยและวุฒิขั้นสูง |
| โรงงาน | 1–3 | 4–6 ต้องมีคนในโรงงานที่ถือวุฒิพื้นฐานอย่างน้อย 1 คนต่อเนื่อง 30 วัน 7–9 ใช้วุฒิขั้นสูง |
| ร้าน | ถึงระดับ 4 | 5–6 ต้องมีคนในร้านที่ถือวุฒิพื้นฐาน ระดับ 7 ใช้วุฒิขั้นสูง ร้านต้นยังไม่ถูกบังคับ |
| ฟาร์ม | 1–3 | ตั้งแต่ระดับ 4 ต้องมีแรงงานฟาร์มที่ถือวุฒิพื้นฐาน ไม่บังคับมหาวิทยาลัย |

เงื่อนไขเดิมเรื่องเงิน ถนน น้ำ ไฟ กำไร และคนทำงานยังอยู่ ตัวตรวจชุดเดียวกันใช้ทั้งการอัปเกรดรายเดือนและข้อความบนแผง

## เวลาที่วัดได้

เมืองตัวอย่าง seed 3 ที่สร้างโรงเรียนติดถนนทันที แล้วสร้างมหาวิทยาลัยในวันที่ได้วุฒิพื้นฐานคนแรก และสร้างโรงไฟฟ้ากับโรงสูบน้ำเมื่อน้ำไฟสำรองหมด:

- ผู้ถือวุฒิพื้นฐานคนแรกวันที่ 64
- ผู้ถือวุฒิขั้นสูงคนแรกวันที่ 175

เมืองที่ไม่มีสถานศึกษาหรือน้ำไฟไม่ครบจะนานกว่านี้ อาคารต่ำยังโตได้ระหว่างรอ

## เซฟ

เมืองที่เปิดการศึกษาบันทึกเป็น v22 `chain-17` พร้อม `education.version = 1` และ `education.rules = education-1` คงเครื่องหมายประชากรและโครงถนนเดิม เซฟเก่าไม่ถูกเติมวุฒิจาก `workerSkills` การเขียนทับเซฟ v9–v21 ครั้งแรกเก็บสำเนาไว้ที่ `citymanager.backup.before-education` ไม่เปลี่ยน guest id หรืออายุ session

ปุ่มในเมนูเกมเปิดเกณฑ์นี้ เมืองที่ไม่ได้เปิดยังใช้กฎเศรษฐกิจเดิม เพื่อให้ชุดทดสอบเดิมผ่าน
