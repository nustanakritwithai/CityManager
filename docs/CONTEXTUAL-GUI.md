# ข้อมูลแยกตามสิ่งที่เลือก

การแก้ GUI รอบนี้เริ่มจากรุ่นที่เผยแพร่ `5c5f396` แผงเดิมมีข้อมูลสถานที่ บัญชีทั้งเมือง และคู่มืออยู่ร่วมกัน ผู้ใช้ต้องการแยกขอบเขตให้ชัดเจน ภาพอ้างอิงสถิติเมืองใช้เป็นแนวทางจัดหมวด ไม่ได้คัดลอกภาพหรือเพิ่มค่าจำลองที่ยังไม่มี

| ทางเข้า | ขอบเขตข้อมูล |
|---|---|
| แตะบ้าน | อาคารนั้น ระดับ อายุ การเข้าถึง และครัวเรือนที่มีบ้านตรงกับอาคารนี้ |
| แตะครัวเรือน | เงิน งาน บ้านปัจจุบัน วันที่ซื้อสินค้า และรายการเงิน/สินค้าที่มีบัญชีครัวเรือนนี้เป็นคู่รายการ |
| แตะโรงงาน/ร้านค้า | บริษัทที่ใช้อาคารนั้น เงิน สินค้าคงคลัง แรงงาน ค่าจ้างสำรอง กำไรรอบก่อน และรายการของบัญชีบริษัทนี้ |
| ภาพรวมเมือง | ยอดคงเหลือและจำนวนปัจจุบัน รายรับ–รายจ่ายคลังและสินค้าในช่วงไม่เกิน 30 วันล่าสุด บัญชีรวม ความต้องการ และคำเตือน |
| คู่มือ | วิธีเล่น สมมติฐาน และเครดิตภาพ |

ครัวเรือนคือหน่วยที่จำลองจริง ไม่ใช่ประชากรรายบุคคล ปุ่มแรงงานของบริษัทเปิดครัวเรือนที่อ้างอิงจริง โดยปุ่มกลับคืนสู่อาคารต้นทาง แม้บ้านพักปัจจุบันจะเป็นคนละอาคารก็ตาม

รุ่นปัจจุบันยังไม่มีจำนวนสมาชิกหรือความจุผู้อยู่อาศัยในข้อมูลบันทึก การเกิดบ้านใน `createBuilding()` สร้างครัวเรือนหนึ่งหน่วยพร้อมกัน ส่วนการเพิ่มระดับใน `grow()` เพิ่มเฉพาะระดับอาคาร ไม่เพิ่มครัวเรือนหรือจำนวนคน GUI จึงแสดงจำนวนครัวเรือนที่อ้างอิงบ้านจริง พร้อมข้อความว่ายังไม่จำลองจำนวนคน/ความจุตามระดับ บ้านที่ไม่มีครัวเรือนอ้างอิงระบุว่าบ้านว่าง ไม่ตีความว่าแต่ละบ้านมีคนตามจำนวนที่คาดเดา

เวอร์ชันถัดไปที่ผู้ใช้อนุมัติแยกอีก PR จะกำหนดความจุตามชนิด/ระดับบ้าน จำนวนคนจริงแยกจากครัวเรือน บ้านใหม่เริ่มว่างแล้วรับผู้ย้ายเข้าตามเงื่อนไข และการอัปเกรดเพิ่มความจุเท่านั้น ค่าความจุและการนำเข้าบันทึกเก่าเป็นการออกแบบของเกมนี้ ไม่ใช่ข้อเท็จจริงจาก Cities: Skylines II

เงินเข้า/ออกนับจากคู่รายการที่เกี่ยวข้องกับคลังเมืองเท่านั้น ช่วงวันที่ระบุรวมวันต้นและวันปลาย ไม่เกิน 30 วัน หากมีวันที่ 0 จะรวมทุนตั้งเมืองตามรายการจริง สินค้าเคลื่อนย้ายคำนวณจาก goods journal ในช่วงเดียวกัน การตัดสต็อกเมื่อรื้อถอนไม่ใช่การส่งออกขาย ยอดคงคลังเป็นจำนวน ณ ปัจจุบัน แยกจากการผลิต/บริโภคในช่วงเวลา

Back/Esc ปิดรายละเอียดบัญชีก่อน กลับจากครัวเรือนไปอาคารต้นทาง แล้วปิดแผงกลับแผนที่ การเปลี่ยนสิ่งที่เลือกเริ่มหน้าใหม่และคืนตำแหน่งเลื่อน การลบอาคาร/ครัวเรือน หรือโหลดเมืองอื่น ล้างรายละเอียดเดิม การเปิดแผงหยุดการเลื่อน/หมุน/ซูมกล้อง แต่การเลือกสถานที่อื่นบนพื้นที่แผนที่ที่มองเห็นยังทำได้

GUI ใช้ DOM เดิมและข้อมูลอ่านอย่างเดียว ไม่เปลี่ยนสูตรเศรษฐกิจ tick, RNG, save schema, โมเดล หรือ dependencies ภาพรวมไม่เปิดอัตโนมัติเมื่อเริ่มเกม การทดสอบมือถือเป็น viewport/touch จำลองใน Microsoft Edge ไม่ใช่โทรศัพท์จริง

## งานเศรษฐกิจถัดไปที่ผู้ใช้ระบุ

งานแยกถัดไปต้องออกแบบแหล่งวัตถุดิบ เช่น ฟาร์ม ไร่นา และเหมือง วัตถุดิบแยกชนิด สูตรแปรรูป สต็อกรายกิจการ และการส่งถึงโรงงาน/ร้านค้าก่อนบริโภค ห้ามสร้างผลผลิตโดยไม่มีวัตถุดิบหรือใช้สินค้าก่อนส่งถึง งานนี้ยังไม่อยู่ใน patch GUI ปัจจุบันและไม่มีค่าดังกล่าวแสดงเป็นข้อมูลสมมติ แผงบริษัทแยกจากหน้ารวมแล้วจึงสามารถเพิ่มส่วนสูตร/วัตถุดิบของบริษัทนั้นในระยะถัดไปได้

## ตรวจซ้ำ

```sh
npm test
npm run assets:verify
npm run build
npm run preview
```

เมื่อ production preview พร้อม เปิดอีก terminal แล้วรัน browser suites ทีละตัว เพราะใช้ Edge profile/port ร่วมกัน:

```sh
npm run test:browser
npm run test:submenus
npm run test:context
```

ทั้งสาม suite ต้องผ่านซ้ำโดยตั้ง `CITYMANAGER_BLOCK_MODELS=1` เพื่อยืนยัน procedural fallback หลักฐานภาพและผลจริงจะบันทึกใน `docs/context-preview/` ก่อนส่ง draft PR ยังไม่มีการอนุมัติ Merge หรือเผยแพร่งาน GUI รอบนี้
