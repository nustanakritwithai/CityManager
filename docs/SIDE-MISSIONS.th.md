# ภารกิจเสริม: เศรษฐกิจหลากหลาย (ชุดแรก)

แสดงใต้การ์ดเป้าหมายใน **ภาพรวมเมือง → เป้าหมาย** ไม่เปลี่ยนเงื่อนไขชนะ 5 ระดับ

| ภารกิจ | เกณฑ์จากเมืองจริง |
|---|---|
| ปลูกพืชให้ครบทุกชนิด | มีฟาร์มปัจจุบันที่ปลูกข้าว ผัก และอ้อย ครบ 3 ชนิด (อิงความอุดมสมบูรณ์ของแปลง) |
| เปิดโรงงานหลายสูตร | มีโรงงานปัจจุบันที่ใช้สูตรโรงสีข้าว โรงงานอาหารกระป๋อง และโรงงานน้ำตาล ครบ 3 สูตร |
| ครัวเรือนซื้อสินค้าหลากหลาย | ใน 30 วันล่าสุดมีบันทึกการซื้อของครัวเรือนครบ ข้าวสาร อาหารกระป๋อง และน้ำตาล (นับชนิด ไม่ใช่จำนวนหน่วย) |

## ข้อตกลง

- อ่านข้อมูลอย่างเดียว: ไม่มีเงินรางวัล ไม่แก้บัญชี ไม่แตะ RNG หรือการจำลอง และไม่เปลี่ยนรูปแบบเซฟ
- วัด **สถานะปัจจุบัน** ไม่ใช่ achievement ที่ปลดล็อกถาวร; เมื่อรื้อฟาร์มหรือโรงงาน คืบหน้าอาจลดลง และการซื้อจะหลุดหน้าต่าง 30 วัน
- ภารกิจสินค้าที่ซื้อ **ไม่ยืนยันว่าสินค้าผลิตในเมือง** เพราะบางส่วนอาจนำเข้า; บอกเฉพาะความหลากหลายของการบริโภค
- ใช้ชนิดพืช สูตร และสินค้าจาก `src/goods.ts` และบันทึกการซื้อ `goodsLedger` ใน `src/sim.ts`
- โหลดเซฟเก่าได้ ไม่มีการประดิษฐ์ข้อมูลย้อนหลังขึ้นมาเอง
- เพิ่มการ invalidation แคชในภาพรวมเมืองและ HUD เมื่อสลับ city object แม้วันและจำนวนบันทึกเท่ากัน เพื่อไม่เห็นข้อมูลเมืองก่อนหน้า

## QA

`tests/city-side-missions.test.ts` ตรวจเมืองใหม่ การนับชนิดจากรายการซื้อ หน้าต่าง 30 วัน การไม่รวมรายการนำเข้า และค่าที่ได้หลัง serialize/deserialize

ก่อน merge ต้องผ่าน `npm test`, `npm run build` และ browser acceptance บน source commit ของ PR

## ความท้าทายขั้นสูง

แยกจากภารกิจเดิมและไม่เป็นเงื่อนไขชนะ: เก็บเกี่ยวพืช 3 ชนิดจริงใน 30 วัน แปรรูปพืช 3 ชนิดจริงใน 30 วัน ให้ครัวเรือนที่มีบ้าน 20 ครัวเรือนซื้ออาหาร และสร้างวงถนนอิสระ 2 วงที่เชื่อมประตูเมือง การนับวงใช้การเชื่อมต่อทางกายภาพ ไม่ยืนยันเส้นทางรถตามทิศวันเวย์ สถานะเป็นข้อมูลปัจจุบันและเปลี่ยนกลับได้ ไม่มีเงินรางวัลหรือข้อมูลความสำเร็จใหม่ในเซฟ ทดสอบใน `tests/city-challenges.test.ts`.
