# แผนสกิล Motion Graphic เล่าเรื่องด้วยแผนที่ (`map-story-motion`)

สถานะ: ร่างแผนรอบ 2 (ปรับตามคลิปตัวอย่างที่ผู้ใช้ส่งมา) ยังไม่เริ่มลงมือ

## 1. เป้าหมาย
ผู้ใช้ส่งเนื้อหาให้ Claude (ข่าว บทความประวัติศาสตร์ เรื่องเล่า "รู้หรือไม่" หรือโจทย์สมมติ) แล้วได้คลิปแนวตั้งแบบเพจสายความรู้บน Facebook Reels / TikTok ที่
- ใช้แผนที่เป็นฉากหลังตลอดคลิป กล้องบิน ซูม แพนไปตามจุดในเรื่อง
- วาดอาณาเขต (ปัจจุบัน ประวัติศาสตร์ หรือสมมติ) ปักหมุด ลากเส้นทาง ใส่ชื่อสถานที่
- มีหัวข้อตัวใหญ่ด้านบน ซับบรรยายด้านล่างที่เน้นคำสำคัญด้วยสี
- เด้งภาพประกอบขึ้นมาบนแผนที่ เช่น การ์ดโพลารอยด์ แผงภาพเหตุการณ์ การ์ดคำศัพท์ ป้ายอันดับ
- ส่งออก 9:16 เป็นหลัก และ 16:9 เป็นทางเลือก

## 2. สไตล์อ้างอิงจากตัวอย่าง
แยกองค์ประกอบที่เห็นในตัวอย่างทั้ง 6 ภาพออกมาเป็นของที่สกิลต้องทำได้

| องค์ประกอบ | เห็นในตัวอย่าง | ชื่อในสกิล |
|---|---|---|
| แผนที่ดาวเทียมโทนมืด | สยาม/ล้านช้าง/เขมร, ไทย-ลาว, ป้อมวิชัยประสิทธิ์ | `basemap: satellite` |
| แผนที่วาดแบบภาพวาด (น้ำทะเลไล่สี ภูเขาเขียว เมฆลอย แผ่นดินเป็นก้อนสีแบน) | พังงา ตะกั่วป่า | `basemap: illustrated` |
| อาณาเขตเส้นเรืองแสง (neon glow) เติมสีโปร่ง ชื่อแคว้นตัวหนาสีเดียวกับเส้น | สยาม พม่า ล้านช้าง เขมร | `area` style `glow` |
| อาณาเขตลายเส้นทแยง (hatch) แสดงส่วนที่สมมติ/ผนวก | ไทยรวมลาว | `area` style `hatch` |
| ไฮไลต์จังหวัดเดียวสีส้มแดง + วงแหวน | จ.พังงา | `area` style `spotlight` |
| แม่น้ำเส้นฟ้าบาง | แม่น้ำโขง เจ้าพระยา | `line` style `river` |
| หมุดวงกลมสีพร้อมป้ายชื่อ / หมุดแดงคลื่นกระจาย | บางกอก, ป้อมวิชัยประสิทธิ์ | `pin` style `dot` / `ripple` |
| เส้นเพชรประรอบจุด (หมุนวน) | อุดง | `pin` style `orbit-diamonds` |
| เส้นทางประ + ไอคอนเดินทาง | เรือจากอินเดีย → พังงา | `route` style `dashed` + `carrier: boat` |
| เส้นประจากหมุดลงไปหาแผงภาพ (leader line) | อุดง → ทหาร, ป้อม → ภาพกำแพง | `callout` |
| แผงภาพเหตุการณ์กว้าง ขอบมนสีธีม | ทหารเขมร, ภาพกำแพงพระนคร | `panel` |
| การ์ดโพลารอยด์เอียงเล็กน้อย ภาพไอคอนข้างใน | เรือ, เครื่องหมายคำถาม | `polaroid` |
| การ์ดกระดาษหลายใบ (คำศัพท์/ความหมาย) บนกรอบกระดาษ | ตะกั่ว / ตะกั่วป่า / ตะกั่วทุ่ง | `word-cards` |
| ป้ายแคปซูลตัวเลข | อันดับ 39 | `badge` |
| หัวข้อตัวใหญ่ขอบดำ/เงา สีเหลือง-แดง หลายบรรทัด | พระเจ้าตากสิ้นพระชนม์อย่างไร, รู้หรือไม่? พังงา | `title` (ซ้อนบนแผนที่ ไม่ใช่ฉากแยก) |
| แถบหัวข้อพื้นสี + ไฮไลต์ใต้ตัวอักษร | รวมกันได้แค่ไหน? | `title` style `banner` |
| ซับขาวขอบดำ เน้นคำด้วยสีเหลือง | เรือจาก **อินเดีย อาหรับ เปอร์เซีย** | `narration` + `**คำเน้น**` |
| ชื่อทะเล/อ่าวตัวเอียงสีจาง ชื่อเมืองเล็กมีจุด | ทะเลอันดามัน อ่าวไทย •ภูเก็ต | `labels` |
| เครดิตแผนที่ + "ขอบเขตแผนที่ - แนวโดยประมาณ" | ภาพสยาม | `credits` |

**สองแบบหลักที่ต้องทำให้ดีตั้งแต่รุ่นแรก**
1. **Satellite + neon** (ภาพ 1, 2, 5): ภาพดาวเทียมมืดลง 40–60% ให้เส้นสีสดเด่น เหมาะกับประวัติศาสตร์ ภูมิรัฐศาสตร์ ข่าว
2. **Illustrated map** (ภาพ 3, 4, 6): แผนที่วาดเอง ทะเลไล่สีน้ำเงิน พื้นดินพื้นผิวหญ้า เมฆโปร่งเลื่อนช้า เหมาะกับสาย "รู้หรือไม่" ที่ดูเป็นมิตร

**เลย์เอาต์แนวตั้ง 1080×1920** (จากตัวอย่าง)
```
┌──────────────────────┐ 0
│   หัวข้อ (0–15%)      │
│                      │
│   แผนที่ + หมุด        │ ← จุดโฟกัสกล้องอยู่ราว 35–45% จากบน
│        ┊ leader      │
│  ┌─แผงภาพ/การ์ด──┐    │ ← 45–75%
│  └─────────────┘  ▮ │ ← ขวา 12% เว้นให้ปุ่มไลก์/แชร์
│   ซับ 2 บรรทัด (72–82%) │
│   เว้นว่าง (82–100%)   │ ← ชื่อเพจ/แคปชันของแพลตฟอร์ม
└──────────────────────┘ 1920
```

## 3. ประสบการณ์ผู้ใช้
```
ผู้ใช้: "ทำคลิปว่าทำไมจังหวัดพังงามีชื่อนี้ สไตล์แผนที่วาด 90 วินาที"
  1. Claude อ่านเนื้อหา ดึงเหตุการณ์ สถานที่ ยุคสมัย ตัวเลข → ร่างสตอรีบอร์ด
  2. แสดงสตอรีบอร์ดเป็นตาราง (ฉาก / ภาพบนแผนที่ / ภาพประกอบ / ซับ / วินาที / อ้างอิง) ให้แก้
  3. หาพิกัดและขอบเขต แสดงภาพนิ่งแผนที่ทุกฉากให้ยืนยัน (โดยเฉพาะอาณาเขตโบราณ)
  4. สร้างภาพประกอบ และหน้า preview ที่เลื่อนดูได้
  5. เรนเดอร์ MP4 + .srt + ภาพปก + ภาพนิ่งรายฉาก + story.yaml ฉบับสุดท้าย
```

## 4. สถาปัตยกรรม
```
เนื้อหา ─► [1 Extract] ─► story.yaml ─► [2 Geo] ─► [3 Assets] ─► [4 Player HTML]
                         (ยืนยัน)      (ยืนยัน)   ภาพประกอบ       │
                                                              ▼
                [6 Mux ffmpeg] ◄── [5 Audio/SRT] ◄── [5 Render เฟรม Playwright]
```

| ส่วน | เลือก | เหตุผล |
|---|---|---|
| เรนเดอร์ | หน้า HTML เดียวที่มี `window.seek(t)` + Playwright จับภาพทีละเฟรม | มี Chromium ในเครื่องอยู่แล้ว ผลเหมือนเดิมทุกครั้ง ไม่ติดไลเซนส์ |
| เครื่องวาดแผนที่ | MapLibre GL JS (ภาพดาวเทียม + เลเยอร์ GeoJSON) | กล้องบิน/เอียง/หมุนได้ ใส่ glow, hatch, dash ได้ |
| แผนที่วาด | เรนเดอร์ GeoJSON เป็นภาพเองบน Canvas/SVG ด้วย d3-geo + พื้นผิว (texture) ทะเล ดิน ภูเขา + เมฆ | ไม่ต้องพึ่ง tile ออนไลน์ ควบคุมสไตล์ได้ทั้งหมด |
| แอนิเมชัน | `state = f(t)` + easing เขียนเอง | seek ไปเวลาไหนก็ได้ |
| เข้ารหัส | ffmpeg H.264 30fps | ทุกแพลตฟอร์มรับ |
| ฟอนต์ไทย | หัวข้อ: Kanit Black / Prompt ExtraBold; ซับ: Kanit SemiBold; ป้ายแผนที่: IBM Plex Sans Thai (OFL ทั้งหมด) | ใกล้ตัวอย่าง ตัดคำถูก |

## 5. อาณาเขตประวัติศาสตร์และสมมติ
ตัวอย่างส่วนใหญ่เป็นเรื่องอาณาจักรโบราณหรือโจทย์ "ถ้า..." จึงต้องมีวิธีสร้างขอบเขตที่ไม่ใช่เขตปัจจุบัน
- **รวมเขตปัจจุบัน**: `union: [TH, LA]` (ไทยรวมลาว) หรือ `union: [TH-82]` (จังหวัด) ใช้ข้อมูล Natural Earth
- **ตัด/เพิ่ม**: `base: KH, add: [TH-31, TH-32, TH-33], subtract: [...]` เช่น เขมรสมัยที่รวมอีสานใต้
- **วาดเอง**: จุดพิกัดเรียงกัน แล้วระบบ snap ขอบที่อยู่ใกล้ชายฝั่งหรือแม่น้ำเข้ากับเส้นจริงอัตโนมัติ ให้ดูไม่หยาบ
- **ทยอยเปลี่ยน**: อาณาเขตยุค A → ยุค B แบบ morph (ใช้ flubber) สำหรับฉาก "ดินแดนที่เสียไป"
- ทุกอาณาเขตที่ไม่ใช่เขตปัจจุบันมีฟิลด์ `approximate: true` → แสดง "ขอบเขตแผนที่ - แนวโดยประมาณ" และอ้างแหล่งใน story.yaml

## 6. รูปแบบข้อมูล `story.yaml`
```yaml
meta:
  title: "รู้หรือไม่? พังงา"
  aspect: [9x16]
  fps: 30
  style: illustrated            # satellite | illustrated
  palette: rookonlok            # ชุดสีธีม (ดูข้อ 8)
  sources: ["ประวัติจังหวัดพังงา, สำนักงานจังหวัด"]
  disclaimer: null              # เช่น "คลิปสมมติ" หรือ "ภาพจำลองโดย AI"
places:
  phangnga: { name: "จ.พังงา", admin: TH-82 }
  phuket:   { name: "ภูเก็ต", lat: 7.88, lng: 98.39, kind: city }
  india:    { name: "อินเดีย", lat: 13.0, lng: 80.2, kind: offscreen }  # ชี้ลูกศร "← อินเดีย"
regions:
  thai:     { label: "ไทย", union: [TH], style: flat, color: gold }
  khmer_old:{ label: "เขมร", base: KH, add: [TH-31, TH-32], style: glow, color: violet, approximate: true }
scenes:
  - id: s1
    title: ["รู้หรือไม่?", "พังงา"]          # หัวข้อค้างบนจอจนกว่าจะเปลี่ยน
    camera: { fit: phangnga, padding: 0.3, move: fly }
    show: [thai, { area: phangnga, style: spotlight }, { polaroid: "icon:question", near: phangnga }]
    narration: "แล้วจังหวัดนี้ **เกิดขึ้นมาได้ยังไง?**"
  - id: s2
    title: ["ดินแดนโบราณ"]
    camera: { fit: [india, phangnga], move: pan }
    show:
      - { route: [india, phangnga], style: dashed, carrier: boat, draw: 2.5 }
      - { polaroid: "icon:sailboat", along: 0.4 }
    narration: "เรือจาก **อินเดีย อาหรับ เปอร์เซีย** แล่นมาค้าขายที่นี่"
  - id: s3
    title: ["ดินแดนแห่งดีบุก"]
    show:
      - { word-cards: [{ word: "ตะกั่ว", note: "= แร่ดีบุก (คำเรียกโบราณ)" }, "ตะกั่วป่า", "ตะกั่วทุ่ง"] }
    narration: "ชื่อ \"ตะกั่วป่า\" มาจาก **แร่ดีบุก** ที่คนโบราณเรียกว่าตะกั่ว"
    ref: "ย่อหน้า 3 ของบทความต้นทาง"
```
- `**...**` ในซับ = คำเน้นสีธีม
- ไม่ระบุ `duration` → คำนวณจากความยาวซับ (ไทย ~5–6 พยางค์/วินาที) หรือความยาวเสียงพากย์จริง + เวลากล้อง
- กล้องที่ไม่ระบุ = ค้างที่เดิมแล้วซูมช้า (Ken Burns) ให้ภาพไม่นิ่ง

## 7. คลังฉาก เอฟเฟกต์ และภาพประกอบ
**กล้อง**: `fly` (โค้งซูมออก-เข้า), `pan`, `zoom`, `orbit`, `hold` (ดริฟต์ช้า), `shake` เบาๆ สำหรับจังหวะดราม่า
**บนแผนที่**: อาณาเขต (flat / glow / hatch / spotlight / morph), เส้นขอบวาดตัวเอง, แม่น้ำ, หมุด (dot / ripple / orbit-diamonds), เส้นทาง (dashed / solid / arrow) + พาหนะวิ่งตามเส้น (เรือ ช้าง ม้า ทัพ รถ เครื่องบิน), ลูกศรชี้ออกนอกจอ, ป้ายชื่อทะเล/เมือง, เมฆลอย (แบบวาด), เครดิตมุมจอ
**ภาพประกอบที่เด้งขึ้น**: `panel` (แผงกว้าง + leader line), `polaroid`, `word-cards`, `badge`, `stat` (ตัวเลขวิ่ง), `quote`, `timeline`, `compare` (ก่อน/หลัง), `photo` (รูปจริง + เครดิต)
**ข้อความ**: `title` (ขอบหนา เงา หลายบรรทัด เด้งเข้า), `title banner`, ซับเน้นคำ, ป้ายวันที่/ยุค (เช่น "พ.ศ. 2310")
**ทรานสิชันการ์ด**: pop + overshoot, เอียง 2–4° แบบโพลารอยด์, เลื่อนขึ้นจากล่าง, หายแบบ scale-out

### วิธีสร้างภาพประกอบ (เลือกได้ต่อชิ้น)
1. **ฉากเวกเตอร์แบนจากชุดชิ้นส่วน (ค่าเริ่มต้น)** เหมือนแผงทหารเขมรในภาพ 1: ฉากหลัง (ฟ้าไล่สี เขา พื้น) + ตัวละครแบบ "ตัวต่อ" (หัว หมวก ลำตัว ชุด อาวุธ ธง เปลี่ยนสีตามฝ่าย) + สิ่งปลูกสร้าง (ปรางค์ เจดีย์ วัง กำแพง บ้านเรือนไทย) + ยานพาหนะ (สำเภา เรือ ช้างศึก ม้า) ทุกชิ้นเป็น layer แยกจึงขยับได้ เช่น ทหารเดิน ธงสะบัด เรือโคลง
2. **ไอคอนในโพลารอยด์** เหมือนเรือใบ/เครื่องหมายคำถามในภาพ 3, 6: คลังไอคอนสไตล์เดียว (เส้นหนา สีพาสเทลอุ่น)
3. **ภาพจาก AI สร้างภาพ (ไม่บังคับ)** เหมือนภาพกำแพงพระนครในภาพ 5: ใช้เมื่อผู้ใช้มีคีย์ API ภาพ สกิลเขียน prompt ให้คุมสไตล์ทั้งคลิป ติดป้าย "ภาพจำลองโดย AI" มุมภาพเสมอ
4. **รูปจริงจากผู้ใช้** + เครดิตอัตโนมัติ

ส่งออกภาพนิ่งทุกชิ้นใน `assets/` + ภาพปก (หัวข้อใหญ่ + แผนที่ฉากเด่น) ให้ใช้โพสต์ต่อได้

## 10. รายละเอียดการเรนเดอร์ที่ต้องระวัง
- ไม่ใช้นาฬิกาจริงคำนวณภาพ ทุกอย่างมาจาก `t`
- MapLibre: ทุกเฟรม `jumpTo(camera(t))` แล้วรอ `idle` ปิด fade ของ tile; คำนวณเส้นทางบินเองเพื่อ seek ได้
- Glow: วาดเส้นซ้อน 3 ชั้น (กว้างจาง → แคบสด) แทน blur เพื่อให้เร็วและคม
- แผนที่วาด: เรนเดอร์ฐานแผนที่ความละเอียดสูงครั้งเดียวต่อฉาก แล้วแพน/ซูมจากภาพนั้น เมฆเป็นชั้นแยกเลื่อนช้ากว่าพื้น (parallax)
- 90 วิ × 30fps = 2,700 เฟรม เป้าหมายเรนเดอร์ < 8 นาที (หลายแท็บขนาน + แคช tile)
- ซับ: `Intl.Segmenter('th')` ตัดบรรทัด ≤ 2 บรรทัด ≤ ~22 ตัวอักษรต่อบรรทัด ไม่เข้าเขตขวา 12% / ล่าง 18%
- เครดิตภาพดาวเทียม/OSM แสดงตลอดฉากแผนที่ ตัวเล็กแต่อ่านได้

## 11. กฎความถูกต้อง (เขียนลง SKILL.md)
- ทุกตัวเลข วันที่ ชื่อ และขอบเขต โยงกลับไปที่เนื้อหาต้นทางได้ (`ref`) ข้อมูลที่ต้นทางไม่มี ห้ามเติมเอง
- อาณาเขตโบราณต้องติด "แนวโดยประมาณ"; เรื่องที่นักวิชาการเห็นต่าง (เช่น ตัวอย่างภาพ 5) ให้เล่าทั้งสองฝั่งและบอกว่าเป็นข้อถกเถียง
- คลิปสมมติต้องมีคำว่า "สมมติ" ในหัวข้อหรือมุมจอตลอดคลิป
- ภาพจาก AI ติด "ภาพจำลองโดย AI" ไม่สร้างใบหน้าบุคคลจริงที่ยังมีชีวิต และไม่ใช้กับข่าวเหตุการณ์ปัจจุบันในลักษณะที่ดูเหมือนภาพถ่ายจริง
- เรื่องเขตแดนที่ยังพิพาทอยู่ในปัจจุบัน ใช้เส้นประและไม่ระบุว่าเป็นของฝ่ายใด เว้นแต่ต้นทางระบุพร้อมแหล่ง
- ข่าวอ่อนไหว ไม่ปักหมุดบ้านหรือข้อมูลส่วนตัว
- ฉากสุดท้ายหรือคำบรรยายใต้คลิปแสดงแหล่งที่มา

## 13. เกณฑ์ตรวจผล
- story.yaml ผ่าน validate ทุก fact มี `ref`
- พิกัด/อาณาเขตตรงกับค่าคาดหวังในเคส (จุด ±2 กม., อาณาเขต IoU ≥ 0.85 สำหรับเขตปัจจุบัน)
- ความยาวคลิปตามสั่ง ±10% ไม่มีเฟรม tile ว่าง
- ข้อความไม่ชนเขตปุ่มของแพลตฟอร์ม สระไทยไม่ลอยผิด ซับ ≤ 2 บรรทัด
- มีเครดิตแผนที่ ป้าย "แนวโดยประมาณ"/"สมมติ"/"ภาพจำลองโดย AI" เมื่อเข้าเงื่อนไข
- เทียบภาพนิ่งกับตัวอย่างอ้างอิงแล้วผู้ตรวจบอกได้ว่า "สไตล์เดียวกัน"

## 14. เรื่องที่ต้องตัดสินใจ
1. **ที่เก็บสกิล**: repo ใหม่ (แนะนำ) หรือ `.claude/skills/` ใน repo นี้
2. **ธีมแรกที่จะทำ**: `neon-history` (ภาพ 1) หรือ `storybook` (ภาพ 3, 4, 6)
3. **เสียงพากย์**: ซับอย่างเดียวในรุ่นแรก หรือต้องมี TTS ไทยตั้งแต่แรก (ผู้ให้บริการไหน)
4. **ภาพจาก AI**: ต้องการแบบภาพ 5 หรือไม่ ถ้าต้องการ ใช้บริการไหน (มีคีย์อยู่แล้วหรือยัง)
5. **ใช้เชิงพาณิชย์หรือไม่** (เพจมีรายได้/รับงาน): มีผลต่อการเลือกภาพดาวเทียมและเพลง
