# แผนสกิล Motion Graphic เล่าข่าวด้วยแผนที่ (`news-map-motion`)

สถานะ: ร่างแผน ยังไม่เริ่มลงมือ

## 1. เป้าหมาย
ผู้ใช้ส่งเนื้อหาให้ Claude (ข้อความข่าว ลิงก์ บันทึกเหตุการณ์ รูปถ่าย) แล้วได้คลิป MP4 แบบ motion graphic ที่
- เปิดด้วยแผนที่ ซูมและแพนกล้องไปทีละจุดตามลำดับเหตุการณ์
- ปักหมุด ลากเส้นทาง ไฮไลต์พื้นที่ และแสดงป้ายเวลา ณ แต่ละจุด
- มีคำบรรยาย (ซับไตเติล และเสียงพากย์ถ้าต้องการ) อธิบายแต่ละช่วง
- แทรกภาพประกอบเหตุการณ์ เช่น ไอคอน การ์ดข้อมูล ไทม์ไลน์ ตัวเลขสถิติ คำพูดอ้างอิง
- ส่งออกได้ทั้งแนวตั้ง 9:16 (TikTok, Reels, Shorts) และแนวนอน 16:9 (YouTube, ข่าวทีวี)

สิ่งที่ไม่ทำในรุ่นแรก: แผนที่ 3D ภูมิประเทศ การตัดต่อฟุตเทจวิดีโอจริง และการสร้างภาพเหมือนจริงของเหตุการณ์จริง (ดูข้อ 9)

## 2. ประสบการณ์ผู้ใช้
```
ผู้ใช้: "ทำคลิปข่าวน้ำท่วมเชียงรายจากบทความนี้ แนวตั้ง 60 วินาที"
  1. Claude อ่านเนื้อหา ดึงเหตุการณ์ สถานที่ เวลา ตัวเลข → ร่างสตอรีบอร์ด
  2. แสดงสตอรีบอร์ดเป็นตาราง (ฉาก / ภาพ / คำบรรยาย / วินาที) ให้ผู้ใช้แก้ก่อน
  3. หาพิกัดทุกสถานที่ แสดงแผนที่ตรวจพิกัดให้ผู้ใช้ยืนยัน
  4. สร้างภาพประกอบ และหน้า preview HTML ที่เลื่อนดูทีละเฟรมได้
  5. เรนเดอร์ MP4 + ไฟล์ซับ .srt + สตอรีบอร์ดฉบับสุดท้าย
```
มีจุดหยุดให้ผู้ใช้ยืนยัน 2 จุด (สตอรีบอร์ด และพิกัด) เพราะสองอย่างนี้ผิดแล้วข่าวผิด

## 3. สถาปัตยกรรม
```
เนื้อหา ─► [1 Extract] ─► story.yaml ─► [2 Geocode] ─► [3 Assets] ─► [4 Player HTML]
                         (ผู้ใช้ยืนยัน)    (ผู้ใช้ยืนยัน)    SVG/รูป        │
                                                                     ▼
                     [6 Mux ffmpeg] ◄── [5 Audio/TTS + SRT] ◄── [5 Render เฟรม Playwright]
                            │
                            ▼
                      out/clip-9x16.mp4, clip-16x9.mp4, clip.srt
```

### ตัวเลือกเทคโนโลยี (ข้อแนะนำ)
| ส่วน | เลือก | เหตุผล |
|---|---|---|
| เรนเดอร์ | หน้า HTML เดียวที่มี `window.seek(t)` + Playwright จับภาพทีละเฟรม | ทำงานในเครื่องที่มี Chromium ได้เลย ผลลัพธ์ deterministic ไม่ติดไลเซนส์ |
| แผนที่ | MapLibre GL JS + vector tiles (OpenFreeMap หรือ Protomaps PMTiles แบบไฟล์เดียว) | ฟรี ปรับสไตล์ได้ทั้งหมด ใส่ภาษาไทยได้ |
| แผนที่สำรองออฟไลน์ | d3-geo + GeoJSON ขอบเขตประเทศ/จังหวัด | ใช้เมื่อไม่มีเน็ตหรือเป็นภาพระดับประเทศ |
| แอนิเมชัน | ฟังก์ชัน `state = f(t)` เขียนเอง + easing (ไม่พึ่งนาฬิกาจริง) | seek ไปเวลาใดก็ได้ภาพเดิมทุกครั้ง |
| เข้ารหัสวิดีโอ | ffmpeg (H.264, yuv420p, 30fps) | มาตรฐาน ทุกแพลตฟอร์มรับ |
| ฟอนต์ไทย | IBM Plex Sans Thai / Noto Sans Thai / Kanit (OFL) ฝังในสกิล | ตัดคำและสระลอยถูกต้อง |
| หาพิกัด | Nominatim (OSM) พร้อมแคช + แก้มือใน story.yaml | ฟรี ระบุแหล่งได้ |
| เสียงพากย์ (ไม่บังคับ) | ไฟล์เสียงที่ผู้ใช้อัด หรือ TTS ที่ผู้ใช้มีคีย์ | ค่าเริ่มต้นคือซับอย่างเดียว ไม่ต้องมีคีย์ |

ทางเลือกที่พิจารณาแล้ว: Remotion (สวย มีระบบ timeline ดี แต่ต้องตั้งโปรเจกต์ React และมีเงื่อนไขไลเซนส์สำหรับบริษัท) จะรองรับเป็น backend ทางเลือกในเฟสหลังถ้าต้องการ

## 4. รูปแบบข้อมูล `story.yaml`
หัวใจของสกิล Claude เขียนไฟล์นี้จากเนื้อหา ผู้ใช้แก้ได้ด้วยมือ ทุกขั้นถัดไปอ่านจากไฟล์นี้อย่างเดียว
```yaml
meta:
  title: "น้ำท่วมเชียงราย 3 วัน"
  language: th
  aspect: [9x16, 16x9]
  fps: 30
  theme: news-dark          # news-dark | news-light | explainer
  sources:                  # แสดงตอนจบคลิป
    - "ไทยพีบีเอส 12 ก.ย. 2569"
places:
  maesai:   { name: "อ.แม่สาย", lat: 20.4330, lng: 99.8780, kind: point }
  river:    { name: "แม่น้ำสาย", geojson: assets/river.geojson, kind: line }
  flood:    { name: "พื้นที่น้ำท่วม", geojson: assets/flood.geojson, kind: area }
scenes:
  - id: intro
    type: title
    text: "น้ำท่วมเชียงราย 3 วัน"
    duration: 3
  - id: s1
    type: map
    camera: { to: maesai, zoom: 12, pitch: 30, bearing: -15, move: fly }   # fly | pan | orbit | hold
    overlays:
      - { pin: maesai, label: "แม่สาย", at: 0.5 }
      - { time_badge: "11 ก.ย. 06:00" }
    narration: "เช้าวันที่ 11 กันยายน ระดับน้ำแม่น้ำสายเริ่มล้นตลิ่ง"
  - id: s2
    type: map
    camera: { fit: flood, move: pan }
    overlays:
      - { area: flood, style: fill-pulse }
      - { route: river, draw: 2.0 }      # วาดเส้นใน 2 วินาที
    narration: "น้ำแผ่ขยายครอบคลุมกว่า 30 ชุมชน"
  - id: s3
    type: card                         # ฉากภาพประกอบ ไม่ใช่แผนที่
    layout: stat
    value: "2,500"
    unit: "ครัวเรือน"
    caption: "ได้รับผลกระทบ"
    illustration: { kind: icon-scene, prompt: "บ้านจมน้ำ เรือกู้ภัย" }
    narration: "มีครัวเรือนได้รับผลกระทบอย่างน้อย 2,500 ครัวเรือน"
  - id: outro
    type: sources
```
ถ้าไม่ระบุ `duration` ระบบคำนวณจากความยาวคำบรรยาย (ภาษาไทยราว 5–6 พยางค์ต่อวินาที หรือจากความยาวไฟล์เสียงจริง) บวกเวลาเคลื่อนกล้อง

## 5. คลังฉากและเอฟเฟกต์ (รุ่นแรก)
**ฉากแผนที่**
- `fly` บินจากจุดเดิมไปจุดใหม่ (โค้งซูมออก-ซูมเข้า) · `pan` เลื่อนขนาน · `orbit` หมุนรอบจุด · `hold` ค้างพร้อมซูมช้า (Ken Burns)
- Overlay: หมุดเด้ง + ป้ายชื่อ, วงคลื่น ripple, เส้นทางที่วาดตัวเอง (พร้อมไอคอนวิ่งตามเส้น เช่น รถ เรือ เครื่องบิน), พื้นที่เติมสี/กะพริบ, ลูกศรทิศทาง, ป้ายเวลา/วันที่, มาตราส่วนและเข็มทิศ, แผนที่ย่อมุมจอบอกตำแหน่งในประเทศ
- จุดหลายจุดพร้อมกัน แสดงเป็นลำดับตามเวลา (timeline-driven)

**ฉากการ์ด/ภาพประกอบ**
- `title`, `stat` (ตัวเลขวิ่ง), `timeline` (เส้นเวลาแนวตั้ง/นอน), `quote` (คำพูด + ผู้พูด), `compare` (ก่อน/หลัง), `list` (ข้อสรุป 3 ข้อ), `photo` (รูปผู้ใช้ + เครดิต + Ken Burns), `sources` (แหล่งข่าวตอนจบ)

**ทรานสิชัน**: ตัดตรง, เลื่อน, ซูมผ่าน (map → card), wipe ตามสีธีม

## 6. ชุดภาพประกอบเหตุการณ์
สามระดับ เลือกได้ต่อฉาก
1. **ไอคอนและฉากเวกเตอร์ (ค่าเริ่มต้น)**: Claude วาด SVG แบบแฟลตจากคลังชิ้นส่วนที่สกิลเตรียมไว้ (บ้าน ถนน รถ เรือ คน ไฟ น้ำ ต้นไม้ อาคารราชการ ฯลฯ) ประกอบตามคำสั่ง `prompt` ใช้พาเลตต์ธีมเดียวกันทั้งคลิป ขยับได้ทีละชิ้น (layer) จึงทำ motion ได้
2. **รูปจากผู้ใช้**: รูปข่าว/รูปถ่าย ใส่เครดิตอัตโนมัติจาก story.yaml
3. **ภาพจาก AI ภายนอก (ไม่บังคับ)**: ถ้าผู้ใช้มีคีย์ API ภาพ จะสร้างเฉพาะภาพเชิงสัญลักษณ์ และติดป้าย "ภาพประกอบ" เสมอ

ผลลัพธ์ทุกภาพเก็บใน `assets/` และส่งให้ผู้ใช้ใช้ต่อได้ (เช่น ทำปกคลิปหรือโพสต์ภาพนิ่ง) สกิลสร้าง **ภาพปก (thumbnail)** และ **ภาพนิ่งรายฉาก** เป็น PNG มาให้ด้วย

## 8. รายละเอียดการเรนเดอร์ที่ต้องระวัง
- **Deterministic**: ห้ามใช้ `requestAnimationFrame`/เวลาจริงในการคำนวณภาพ ทุกอย่างมาจาก `t` เดียว
- **แผนที่**: ทุกเฟรมเรียก `map.jumpTo(camera(t))` แล้วรอ event `idle` (tile โหลดครบ) ก่อนจับภาพ ปิด fade ของ tile และ label collision animation
- **เส้นทางกล้อง**: คำนวณ fly path แบบ van Wijk (แบบเดียวกับ `flyTo`) เองจาก `t` เพื่อให้ seek ได้
- **ความเร็ว**: 60 วินาที × 30fps = 1,800 เฟรม ตั้งเป้าเรนเดอร์ไม่เกิน ~5 นาที ใช้หลายแท็บขนานกันได้ และแคช tile ในดิสก์
- **ขนาดจอ**: 1080×1920 และ 1920×1080; จัด safe area ไม่ให้ซับชน UI ของแพลตฟอร์ม (ล่าง 20% ในแนวตั้ง)
- **ภาษาไทย**: ตัดบรรทัดซับด้วย `Intl.Segmenter('th', {granularity:'word'})` ไม่เกิน 2 บรรทัด
- **ลิขสิทธิ์แผนที่**: แสดง "© OpenStreetMap contributors" มุมจอตลอดฉากแผนที่

## 9. กฎสำหรับงานข่าว (เขียนลง SKILL.md)
- ทุกตัวเลข วันที่ และสถานที่ในคลิปต้องโยงกลับไปที่ประโยคในเนื้อหาต้นทางได้; สตอรีบอร์ดมีคอลัมน์ "อ้างอิง"
- ข้อมูลที่เนื้อหาไม่มี ห้ามเติมเอง ให้ถามผู้ใช้หรือเว้นไว้
- พิกัดที่หาไม่ได้แน่ชัด (ชื่อซ้ำ ระดับหมู่บ้าน) ต้องแจ้งผู้ใช้ ไม่เดา
- ภาพที่สร้างขึ้นติดป้าย "ภาพประกอบ" ไม่ทำภาพเหมือนจริงของบุคคลจริงหรือเหตุการณ์จริง
- ฉากจบแสดงแหล่งที่มาเสมอ
- ข่าวอ่อนไหว (ผู้เสียชีวิต เด็ก ผู้เสียหาย) ไม่ระบุตำแหน่งบ้านหรือข้อมูลส่วนตัวบนแผนที่

## 10. ลำดับการพัฒนา
| เฟส | งาน | ผลที่ส่งได้ |
|---|---|---|
| 0 | สเปก `story.yaml` + `validate-story.mjs` + ตัวอย่าง 2 เรื่อง | สคีมาที่ล็อกแล้ว |
| 1 | Player: ฉาก `map` (fly/pan/hold) + หมุด + ป้ายเวลา + ซับ, `render.mjs` → MP4 | คลิปแรกที่เป็นแผนที่ล้วน |
| 2 | เส้นทาง พื้นที่ แผนที่ย่อ ทรานสิชัน; ฉาก title/stat/timeline/quote/sources | คลิปข่าวครบโครง |
| 3 | คลังไอคอน SVG + การประกอบภาพประกอบ + ภาพปกและภาพนิ่งรายฉาก | ชุดภาพประกอบ |
| 4 | `geocode.mjs`, ขั้นดึงเหตุการณ์จากข่าว (ใน SKILL.md), จุดยืนยัน 2 จุด | ใส่ข่าวดิบแล้วได้คลิป |
| 5 | เสียง: รับไฟล์พากย์ / TTS เสริม, จังหวะฉากตามเสียงจริง, เพลงพื้นหลัง CC0 | คลิปมีเสียง |
| 6 | evals 6–8 เรื่อง, `doctor.mjs`, ปรับ description ให้ trigger ถูก (ใช้ skill-creator) | สกิลพร้อมแจก |

เฟส 0–2 คือ MVP ที่ใช้งานได้จริง

## 11. เกณฑ์ตรวจผล (evals)
- story.yaml ผ่าน validate และทุก fact มีอ้างอิง
- พิกัดทุกจุดอยู่ในพื้นที่ที่ถูกต้อง (เทียบค่าคาดหวังในเคสทดสอบ ±2 กม.)
- คลิปยาวตามสั่ง ±10% ไม่มีเฟรมว่าง/tile ยังไม่โหลด (ตรวจด้วยการเทียบเฟรมสุ่มกับสีพื้นหลัง)
- ซับไม่ล้นจอ ไม่ตกขอบ safe area สระไทยไม่ลอยผิด
- มีเครดิต OSM และฉากแหล่งที่มา
- ผู้ตรวจดูแล้วเข้าใจลำดับเหตุการณ์จากคลิปโดยไม่อ่านข่าว

## 12. เรื่องที่ต้องตัดสินใจ
1. **ที่เก็บสกิล**: แยกเป็น repo ใหม่ (แนะนำ เพราะไม่เกี่ยวกับเกม CityManager) หรือเก็บใน `.claude/skills/` ของ repo นี้
