# หลัง 1.0: ระบบที่อาจทำต่อ

รุ่น 1.0 ปิดงานแล้ว รายการนี้เป็นแนวทาง ไม่ใช่สัญญา ทุกระบบยังต้องใช้หลักเดิม: เงินเป็นสตางค์จำนวนเต็ม ผลแน่นอนตาม seed ทุกรายการมีบัญชี และอธิบายได้ ระบบที่ต้องเปลี่ยนรูปแบบเซฟจะเริ่มรุ่น 2.0 (เซฟ v8)

| ระยะ | ระบบ | ผลต่อเกม | เซฟ |
|---|---|---|---|
| A | นโยบายและงบเมือง: ปรับภาษีค่าจ้าง/กำไร/ค่าเช่า หน้างบรายเดือนและคาดการณ์ | เงินคลังมีความหมาย ภาษีส่งผลต่อการย้ายเข้าและการขยายกิจการ | v8 (`policy`) |
| B | ภารกิจเสริม: การ์ดภารกิจจากสัญญาณที่มีอยู่ เช่น ไม่นำเข้า 30 วัน ทุกครัวเรือนมีงาน | เป้าหมายระหว่างทางหลังชนะ | ไม่ต้อง |
| C | เครือข่ายน้ำและไฟ: โรงสูบน้ำ โรงไฟฟ้า รัศมีและกำลังผลิต | การวางผังเชิงพื้นที่ | v8 |
| D | บริการและมูลค่าที่ดิน: สวน โรงเรียน (ฝึกทักษะ) คลินิก | เมืองยกระดับคุณภาพ ไม่ใช่แค่จำนวน | v8 |
| E | เหตุการณ์ตาม seed: ภัยแล้ง ราคาส่งออกขึ้นลง ประกาศล่วงหน้า 1 เดือน | ความท้าทายที่รับมือได้ | v8 |
| F | Typhoon สำหรับร้านค้าของครัวเรือน | ผู้ช่วยเจ้าของครอบคลุมทุกกิจการของครัวเรือน | ต้องตัดสินใจร่วมกับเจ้าของงาน Typhoon |

ลำดับที่แนะนำ: A → B → C → D → E (F แทรกได้เมื่อพร้อม)
