# ความพร้อมเมืองก่อนขึ้นระดับสูง: งานถัดไป

สถานะ: ข้อกำหนดออกแบบ ยังไม่บังคับใช้ในเกม ชุดแก้แผงข้อมูลนี้ไม่เปลี่ยนสูตรเศรษฐกิจหรือเงื่อนไขเติบโต

## ข้อเท็จจริงของระบบปัจจุบัน

- ตรวจการเติบโตทุกสิ้นเดือน ใช้ถนน น้ำไฟ ผู้ทำงาน กำไรและเงินตามกติกาแต่ละประเภท
- มีสวน การจ้างคนดูแล ผู้มาใช้ และผลการพักผ่อนแล้ว
- ยังไม่มีบริการโรงเรียนหรือผลสัมฤทธิ์การศึกษา และค่ามลพิษในระบบสัญญาณระบุว่าไม่มีข้อมูล
- ห้ามนำจำนวนสวนแทนคุณภาพสิ่งแวดล้อม หรือจำนวนทักษะแรงงานแทนผลการศึกษาโดยไม่กำหนดระบบจริง

## เป้าหมายตามคำขอผู้เล่น

อาคารระดับสูงต้องผ่านความพร้อมบริการเมือง ไม่โตเพียงเพราะมีเงิน ปัจจัยร่วมคือสิ่งแวดล้อม การศึกษา และสาธารณูปโภคที่ให้บริการจริงอย่างต่อเนื่อง แผงอาคารแสดงค่าปัจจุบัน เกณฑ์ ความคืบหน้า ระดับถัดไป และเหตุผลที่ยังไม่ผ่าน

## ลำดับงานที่เสนอ

1. สร้างข้อมูลบริการจริง: แหล่งบริการ ผู้ทำงาน งบดำเนินงาน ความจุและผู้ได้รับบริการ โดยไม่สร้างเงินหรือบุคลากรขึ้นฟรี
2. นิยามสิ่งแวดล้อมแยกจากการพักผ่อนในสวน และการศึกษาตามกลุ่มเป้าหมาย ไม่เฉลี่ยข้อมูลที่ไม่มีให้เป็นศูนย์
3. กำหนดเกณฑ์ตามประเภท/ระดับอาคารอย่างชัดเจน พร้อมช่วงเวลารักษาคุณภาพและระยะรอระหว่างการอัปเกรด ค่าตัวเลขต้องปรับจากการทดสอบสมดุล ไม่ตั้งเกณฑ์แล้วอ้างว่าผ่านทดสอบ
4. ใช้ตัวประเมินเดียวกันใน simulation และแผง UI; แยกผลผ่าน/ไม่ผ่าน/ข้อมูลยังไม่รองรับ
5. วางนโยบายเซฟเดิมก่อนบังคับใช้: ไม่ลดระดับอาคารหรือไล่คนออกย้อนหลัง; เสนอให้ใช้เกณฑ์ใหม่กับการอัปเกรดครั้งต่อไป พร้อมรุ่นเซฟและขอบเขตเวลาเริ่มกติกา
6. ทดสอบไม่เกิดทางตัน: เมืองระดับต่ำยังสร้างและจ่ายค่าบริการที่จำเป็นต่อการปลดล็อกขั้นถัดไปได้ และบริการหยุดชั่วคราวไม่ทำให้อาคารลดระดับทันที

ยังไม่ควรล็อกการอัปเกรดด้วยโรงเรียนที่ผู้เล่นสร้างไม่ได้ งานนี้ต้องทำบริการและเกณฑ์ปลดล็อกด้วยกันก่อนเปิดใช้จริง
