# พาณิชย์ระดับ 1: ตลาด

รุ่นนี้รวมตลาดเข้ากับหมวดพาณิชย์ตามคำขอของผู้เล่น โซนที่สร้างได้เหลือ R / C / I / F ไม่มีปุ่มหรือโซนตลาด T แยกต่างหาก การเลือก C สร้างกิจการตลาดระดับ 1 เมื่อมีถนน สาธารณูปโภค ฟาร์ม ผู้ซื้อ และครัวเรือนเจ้าของที่มีทุนและแรงงานตามกติกาเดิม

ตลาดยังซื้อและขายพืชผลจากสต็อกเดียวกัน ขายให้โรงงานหรือครัวเรือนได้ เงินกิจการแยกจากเงินครัวเรือน เจ้าของใช้แรงงานจากจำนวนที่มีจริง การเติมทุน ถอนกำไร ภาษี และการสำรองภาระผูกพันยังใช้กติกาเดิม การรวมหมวดไม่แจกเงิน สินค้า แรงงาน หรือความต้องการซื้อเพิ่ม

## ระดับและกิจการเดิม

- พาณิชย์ระดับ 1 คือกิจการตลาด (`commercialKind: market`) ใช้แรงงานเจ้าของหนึ่งหน่วยตามเดิม
- ร้านค้าสินค้าสำเร็จรูปในเซฟเก่ายังคงเป็นกิจการเดิม (`commercialKind: retail`) ระดับเก่า 1 / 2 / 3 แสดงเป็นพาณิชย์ระดับ 2 / 3 / 4 เพื่อไม่ใช้ระดับ 1 ซ้ำกับตลาด ความจุงานของร้านค้าเท่ากับระดับใหม่ลบหนึ่ง จึงรักษา 1 / 2 / 3 ตำแหน่งงานเดิม
- ร้านค้าเก่าที่มีกำไรยังเติบโตได้ตามกติกาเดิมภายในระดับที่ย้ายแล้ว ไม่ได้เพิ่มประเภทร้านค้า สูตรการผลิต หรือระบบเจ้าของใหม่
- ตลาดระดับ 1 ยังไม่เปลี่ยนเป็นร้านค้าระดับ 2 อัตโนมัติ เพราะทั้งสองกิจการขายสินค้าต่างชนิดและใช้ทุน/แรงงานต่างกัน การเปลี่ยนรูปแบบกิจการต้องออกแบบการจัดการสต็อกและภาระผูกพันในรุ่นถัดไปก่อน

การย้ายระดับเป็นทางเลือกเพื่อรักษากิจการที่เล่นอยู่ ไม่ใช่การอ้างว่ามีระบบพาณิชย์ขั้นสูงครบแล้ว

## ความเข้ากันได้ของเซฟ

ข้อมูลใหม่ใช้ `5 / commercial-1` และ `citymanager.save.v5` การอ่านเซฟ v4 ตรวจความถูกต้องด้วยตัวอ่านกติกาเดิมก่อน จึงย้ายโซน T เป็น C พร้อมชนิดตลาดและรักษาระดับ 1 ส่วนโซน C ร้านค้าเก่าเลื่อนหมายเลขระดับตามตารางข้างต้น การอ่าน v1–v3 ผ่านการตรวจและย้ายข้อมูลเดิมก่อนใช้กติกานี้

ID อาคาร/กิจการ เจ้าของ บัญชี เงิน สินค้าสำเร็จรูป พืชผล ต้นทุนสต็อก แรงงาน วันทำงานที่ค้างจ่าย ภาระภาษี และสมุดรายการเดิมต้องคงอยู่ การโหลดไม่เดินเวลา ไม่สุ่มใหม่ ไม่บันทึกทับอัตโนมัติ และการโหลดซ้ำไม่ย้ายระดับซ้ำ เซฟต้นฉบับ v1–v4 คงอยู่แยกจากช่องใหม่ พร้อมสำรอง bytes ก่อนการบันทึกหลังนำเข้า

สัญลักษณ์ T ที่ยังอยู่ในกติกาการแลกเปลี่ยนพืชผลภายในหรือโค้ดอ่านเซฟเก่า หมายถึงช่องทางผู้ค้าตามประวัติ ไม่ใช่โซนที่สร้างได้ ข้อมูลสัญญาณและคำถามในเกมรักษา ID ของสัญญาเดิม โดยนับตลาดเป็นส่วนหนึ่งของพาณิชย์ ไม่สร้างกิจการซ้ำ

## การตรวจรับ

ตรวจการสร้างผ่านปุ่ม C และไม่มีปุ่ม T, หน้าข้อมูลพาณิชย์ระดับ 1 กับร้านค้าเดิม, เงิน/สต็อก/แรงงาน/ค่าจ้างหลังย้ายเซฟ, การโหลดซ้ำ, สายฟาร์ม–ตลาด–โรงงานและการขายตรงให้ครัวเรือน รวมทั้ง Back/Esc เซฟ และหน้าจอมือถือ ใช้ชุด regression ปกติและกรณีโมเดลโหลดไม่ได้ ผลจริงและ source commit ระบุใน PR ของรุ่นนี้ ยังไม่ถือว่าเผยแพร่จนได้รับอนุมัติและตรวจเว็บจริง

ไม่เปลี่ยน Typhoon/backend ไม่เพิ่มอุตสาหกรรม ระบบราคา หรือการลงทุนใหม่ การตรวจมือถือในเครื่องพัฒนาเป็น viewport/touch emulation ไม่ใช่ Galaxy S22 เครื่องจริง
