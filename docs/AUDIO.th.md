# เสียงในเกม (รุ่น 1.1)

เสียงเป็นงานนำเสนอเท่านั้น อ่านสถานะเมืองอย่างเดียว ไม่แตะการจำลอง เซฟ หรือตัวสุ่มของเมือง ทุกเสียงมีภาพหรือข้อความคู่กันเสมอ ผู้เล่นที่ปิดเสียงจึงไม่พลาดข้อมูล

## ระบบ (`src/audio-engine.ts`)
- **เริ่มหลังแตะครั้งแรก**: เบราว์เซอร์ไม่ให้เล่นเสียงก่อนผู้ใช้แตะหน้าจอหรือกดปุ่ม การแตะ/กดครั้งแรกจึงสร้างระบบเสียงและโหลดเสียงประกอบทั้ง 20 เสียง (ราว 100 KB)
- **4 กลุ่มเสียงใต้เสียงรวม**: ปุ่มและเครื่องมือ · เหตุการณ์ในเมือง · บรรยากาศ · เพลง มีตัวกันเสียงแตก (compressor) ก่อนออกลำโพง
- **หยุดเมื่อแท็บถูกซ่อน** และกลับมาเมื่อเปิดแท็บ เพลงหยุดเมื่อระดับเพลงเป็นศูนย์หรือปิดเสียง
- **ตั้งค่า** (`src/audio-settings.ts`): เปิดเสียงเป็นค่าเริ่มต้นที่ระดับเบา (เสียงรวม 55% เพลง 35%) เก็บใน `citymanager.audio.v1` ของเบราว์เซอร์ ปรับได้ในเมนูบรรยากาศ ☀ (`src/audio-panel.ts`) กด **U** ปิด/เปิดเสียง

## เสียงปุ่มและเครื่องมือ
เลือกเครื่องมือ · วางโซน · สร้างถนน · รื้อ · คำสั่งที่ทำไม่ได้ (เสียงปฏิเสธเบา ๆ) · เปลี่ยนความเร็ว/หยุดเวลา · บันทึก · เปิด/ปิดแผงข้อมูล

## เสียงเหตุการณ์ในเมือง (`src/audio-cues.ts`)
เทียบสถานะก่อนและหลังเวลาเดิน เหมือนรายการเหตุการณ์ในหน้าเครือข่ายเมือง
- อาคารสร้างเสร็จ (บ้าน/ตลาด · ร้าน/โรงงาน · ฟาร์ม คนละเสียง) · ครัวเรือนย้ายเข้า · สิ้นเดือน (เสียงเหรียญ) · ร้านค้าเปิดหรือตลาดยกระดับ · ป้ายปัญหาใหม่ · กิจการเงินหมด
- ระดับเมืองขึ้นและชนะมีเพลงสั้นของตัวเอง
- **กันเสียงรัวตอนเร่ง 10×**: ไม่เกิน 3 เสียงต่อวินาที เสียงชนิดเดียวกันห่างกันอย่างน้อย 0.9 วินาที เพลงสั้นตอนระดับขึ้นหรือชนะเล่นเสมอ เสียงเหรียญสิ้นเดือนเล่นตามวันที่ข้ามเดือน รวมวันที่เศษนาทีเดิมทำให้วันจบ และไม่เข้าเพดาน 3 เสียง การโหลดเซฟหรือเริ่มเมืองใหม่ไม่เล่นเสียงย้อนหลัง และล้างตัวกันเสียงของเมืองก่อนหน้า

## เสียงบรรยากาศ (สร้างในเบราว์เซอร์ ไม่ต้องโหลดไฟล์)
- **ฝน** ตามฝนบนจอ · **ลม** ดังขึ้นเมื่อซูมออก · **เสียงเมือง** ตามประชากร ชัดขึ้นเมื่อซูมเข้า · **โรงงาน** เมื่อโรงงานแปรรูปจริงในวันนั้น
- **นก** กลางวัน **จิ้งหรีด** กลางคืน ตามนาฬิกาบรรยากาศ เงียบเมื่อฝนตก

## เพลง
เล่นวนสามเพลงต่อกัน (เว้น 6 วินาทีระหว่างเพลง) เริ่มจากเพลงสุ่ม กด "เพลงถัดไป" ในเมนูได้ เพลงสตรีมเมื่อเริ่มเล่นเท่านั้น ไม่โหลดล่วงหน้า

## ที่มาและสัญญาอนุญาต (ทั้งหมด CC0)
| ไฟล์ | ที่มา |
|---|---|
| เสียงปุ่ม เหตุการณ์ | Kenney: [Interface Sounds](https://kenney.nl/assets/interface-sounds), [Impact Sounds](https://kenney.nl/assets/impact-sounds), [RPG Audio](https://kenney.nl/assets/rpg-audio) |
| เพลงสั้น (ระดับขึ้น/ชนะ) | Kenney: [Music Jingles](https://kenney.nl/assets/music-jingles) |
| Another August, Vaporware | The Cynic Project (cynicmusic.com) ผ่าน [OpenGameArt](https://opengameart.org/content/another-august) |
| Apple Cider | Zane Little Music ผ่าน [OpenGameArt](https://opengameart.org/content/apple-cider) |

- `scripts/prepare-audio-assets.mjs <โฟลเดอร์ดาวน์โหลด>` แปลงไฟล์ต้นฉบับเป็น MP3 (เสียงประกอบโมโน 80 kbps เพลงสเตอริโอ 96 kbps ไม่มี metadata) และเขียน `public/assets/audio/manifest.json` พร้อม SHA-256 ของต้นฉบับและไฟล์ที่ได้
- `npm run assets:verify` ตรวจรายการไฟล์ปิด (ไม่มีไฟล์เกินหรือขาด) hash ไฟล์สัญญาอนุญาต CC0 และงบขนาด (เสียงประกอบ ≤ 300 KB เพลง ≤ 8 MB)
