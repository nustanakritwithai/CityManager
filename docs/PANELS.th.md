# แผงข้อมูล: ไอคอน รูปภาพ และตัวอักษร

แผงข้อมูลทุกหน้าเป็นชั้นแสดงผลอย่างเดียว อ่านจาก `City` แต่ไม่แก้ไข และไม่เข้าเซฟ (`serialize(city)` เท่าเดิมทุกครั้ง)

## หลักการ
- **ตัวเลขนำ ตัวหนังสือรอง:** ทุกช่องตัวเลขมีไอคอน ป้ายอยู่บรรทัดเดียว คำอธิบายยาวพับไว้หลังปุ่ม ⓘ บนหัวข้อของหมวด
- **รูปแทนรายการ:** สมาชิกครัวเรือนเป็นรูปคน (เขียว ทำงาน · เหลือง ว่างงาน · ฟ้า ผู้พึ่งพิง), ความจุเล็กเป็นจุดหนึ่งจุดต่อหนึ่งช่อง, ที่พักทั้งเมืองเป็นแถบเกจ, แรงงานทั้งเมืองเป็นโดนัท
- **เงื่อนไขเป็นไอคอน:** การขยายโรงงานและแปลงว่างแสดงเป็นแถวไอคอนพร้อม ✓ / ! ตัวหนังสือเหลือเฉพาะข้อที่ยังติด แตะแถวเพื่อดูทั้งหมด
- **กิจการเป็นแถบไหลงาน:** วัตถุดิบ › แปรรูป › สินค้า (โรงงาน), ดิน › เก็บเกี่ยว › คลัง (ฟาร์ม), พืชผล/สินค้า › คนขาย › เงิน (ตลาด/ร้าน)
- **ข้อความยังอยู่ครบใน DOM** (ซ่อนด้วย class) โปรแกรมอ่านหน้าจอ การค้นหา และชุดทดสอบยังอ่านได้

## โมดูล
| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/ui-icons.ts` | ไอคอน SVG 24×24 ชุดเดียว ใช้ในแผง แผงสถิติ และ HUD |
| `src/panel-decor.ts` / `.css` | ใส่ไอคอนให้ช่องตัวเลข, ปุ่ม ⓘ, รูปคน, เกจ, แถบไหลงาน, แถวไอคอนเงื่อนไข (idempotent, รันหลัง render และผ่าน MutationObserver) |

| `src/overview-panels.ts`, `src/overview-data.ts` | แดชบอร์ดการเงิน ห่วงโซ่สินค้า และเช็กลิสต์การขยายโรงงาน |

| `src/panels.css` | โทเคนสีและสไตล์รวมของแผง โหลดท้ายสุด |

## ตัวอักษรและหน่วย
- ฟอนต์ **IBM Plex Sans Thai** (SIL Open Font License 1.1) จากแพ็กเกจ `@fontsource/ibm-plex-sans-thai` ชุดอักษรไทยและละติน น้ำหนัก 400/600/700 รวมประมาณ 92 kB ฝังมากับ build ไม่โหลดจากภายนอก
- ขนาดตัวอักษรใช้ `--reader-unit` และไม่เล็กกว่าเกณฑ์ของชุดทดสอบ (14px ตามกายภาพสำหรับเนื้อหา, ปุ่ม ≥ 44px)
- หน่วยเงินที่แสดงคือ **฿** (100 สตางค์ = 1 ฿)

## HUD รอบสอง
- พื้นผิวกระจกฝ้า (`backdrop-filter` เฉพาะคุณภาพกลาง/สูง), ปุ่มที่เลือกอยู่เรืองแสง, ปุ่มโซนเรืองตามสีโซน
- แถบสรุปบนมีไอคอนทุกช่อง และวันชำระรายเดือนเป็นวงแหวน
- ข้อความผลการกระทำเป็น toast มีจุดสีตามผล (ข้อมูล / สำเร็จ / ต้องแก้)
- หัวแผงไล่สีตามสิ่งที่เลือก (บ้าน พาณิชย์ ตลาด โรงงาน ฟาร์ม ถนน ครัวเรือน เมือง ฯลฯ) และทุกหมวดมีไอคอนนำหน้า
- เปลี่ยนเฉพาะสี เงา และความโปร่ง ไม่เปลี่ยนขนาดหรือตำแหน่ง (`src/hud.css`)
- ภาพ: [hud-round2.jpg](visual-redesign-preview/hud-round2.jpg), [panels-round2.jpg](visual-redesign-preview/panels-round2.jpg)

## กราฟของเมือง
- ข้อมูลย้อนหลังสร้างจากสิ่งที่อยู่ในเซฟอยู่แล้ว (`src/city-series.ts`): บัญชีเงิน สินค้า และพืชผลทุกวัน, ประชากรจากวันที่แต่ละครัวเรือนย้ายเข้า, อาคารจากอายุอาคาร (นับเฉพาะอาคารที่ยังอยู่) ทดสอบแล้วว่าตรงกับยอดภาพรวมเมืองและสถานะจริงของแต่ละวัน
- แดชบอร์ดภาพรวมเมือง: การ์ดตัวเลข 4 ใบ (เงินคลัง ประชากร มีงานทำ ที่พักใช้ไป) พร้อมเส้นแนวโน้ม/มาตรวัด, กราฟเงินคลัง, รายรับ–รายจ่ายรายวัน (แท่งขึ้น/ลง), พืชผลรายวัน, สินค้ารายวัน, ประชากร, อาคารตามประเภท และแท่งสัดส่วนรายรับ รายจ่าย อาคาร และบทบาทประชากร
- ปุ่มขยายบนทุกกราฟเปิดหน้าต่างใหญ่ (`src/chart-modal.ts`): ช่วง 7/30/90 วัน/ทั้งหมด, แตะชื่อชุดข้อมูลเพื่อซ่อน/แสดง, หมุดเหตุการณ์ใต้แกนเวลา (สร้างอาคาร ต่อถนน ครัวเรือนย้ายเข้า ปิดกิจการ) และตาราง "ช่วงนี้" (เฉลี่ยต่อวัน รวมหรือล่าสุด สูงสุด) ปิดด้วย ✕ หรือ Esc
- ชุดสีกราฟใช้ลำดับสีมาตรฐาน 8 สี (`--series-1` … `--series-8` ใน `src/tokens.css`) ตรวจด้วยตัวตรวจสีแล้วบนพื้นกราฟ `#1d3a44` สีของแต่ละชุดผูกกับสิ่งนั้นตายตัว (เช่น ร้านค้า โรงงาน บ้าน ฟาร์ม ตลาด) ไม่เปลี่ยนตามอันดับ
- ทุกกราฟมีเส้นชี้ค่า (เมาส์ แตะ หรือปุ่มลูกศรเมื่อโฟกัส) คำอธิบายสีเมื่อมี 2 ชุดขึ้นไป และ "ดูเป็นตาราง" เพื่อไม่ให้ค่าใดขึ้นกับสีหรือการชี้อย่างเดียว
