# บรรยากาศและโลกรอบเมือง (ชิ้น 4A–4B)

ส่วนหนึ่งของ [แผนปรับความสวยงาม](VISUAL-REDESIGN-PLAN.th.md) ข้อ 8 ทั้งหมดนี้เป็น **ภาพเท่านั้น**: ไม่อ่านหรือเลื่อน RNG ของระบบจำลอง ไม่แก้ `City` และไม่ถูกบันทึกในเซฟ หนึ่ง tick ยังเท่ากับหนึ่งวันตามเดิม

## เวลาในวัน
- ที่ความเร็ว 1× วันในเกมผ่านไปวันละ 1 วินาที ถ้าผูกท้องฟ้ากับ tick ตรงๆ จอจะกระพริบ จึงใช้นาฬิกาภาพแยก: **1 รอบวัน = 300 วินาทีจริงที่ 1×** (`DAY_CYCLE_SECONDS`) ที่ 3× และ 10× เร็วขึ้นตาม √ความเร็ว แต่ไม่เกิน 2 เท่า และหยุดเมื่อกด Pause
- โหมด: อัตโนมัติ, เช้า (08:00), กลางวัน (12:30), เย็น (17:24), กลางคืน (21:30), ตามเวลาเครื่อง เลือกจากปุ่มนาฬิกาในแถบเวลา
- ดวงอาทิตย์ขึ้นทางตะวันออก (+x) ผ่านทิศใต้ แล้วตกทางตะวันตกฝั่งประตูเมือง ตอนกลางคืนใช้แสงจันทร์สีฟ้าอ่อน และ ambient ขั้นต่ำที่ยังอ่านโซน ถนน และตัวเลือกได้

## ไฟกลางคืนสะท้อนข้อมูลจริง
- หน้าต่างติดไฟ **เฉพาะ** บ้านที่มีครัวเรือนอยู่จริง และกิจการที่มีแรงงานจัดสรรอยู่ (`firmWorkerCount > 0`) อาคารว่างจะมืด
- ไฟจากโมเดล Kenney ใช้ mask เฉพาะช่องกระจกใน color atlas (บ้าน/ร้าน x 320–384, y 128–256; โรงงาน x 256–320, y 384–512; หลอดไฟถนน x 256–320, y 256–384) จึงไม่ทำให้ทั้งอาคารเรืองแสง
- ไฟถนนมีวงแสงบนพื้น (additive) สว่างตามระดับกลางคืน

## ฤดูกาลและฝน
- เดือนในเกม 1 = มกราคม แบ่งฤดูแบบไทยและไล่สีต่อเนื่อง: ร้อน (มี.ค.–พ.ค.) อุ่นและมีหมอกแดด, ฝน (มิ.ย.–ต.ค.) เทาและเย็นขึ้น, หนาว (พ.ย.–ก.พ.) ฟ้าใส
- ฝนตกแบบตกแต่ง ตัดสินทุก 75 วินาทีจริง (`WEATHER_PERIOD_SECONDS`) จาก hash ของ seed เมืองกับช่วงเวลา จึงไม่เปลี่ยนเร็วตามความเร็วเกม โอกาสประมาณ 55% ในฤดูฝน, 7% ฤดูร้อน, 2% ฤดูหนาว
- ฝนวาดบน canvas 2D แยกเหนือแผนที่และใต้ HUD ไม่บังการคลิก และหยุดเคลื่อนไหวเมื่อเปิด `prefers-reduced-motion`
- ปิดฤดูกาลหรือฝนได้ในเมนูบรรยากาศ

## คุณภาพภาพ
| ระดับ | เงา | Post-processing |
|---|---|---|
| ต่ำ | ไม่มี | tone mapping ACES อย่างเดียว (ค่าเริ่มต้นเมื่อไม่มี GPU) |
| กลาง | 1 cascade 1024px | CameraFrame: ACES, MSAA 2×, bloom, color grading, vignette |
| สูง | 2 cascades 2048px | เหมือนกลาง + SSAO และ MSAA 4× |

- **อัตโนมัติ** เลือก "กลาง" บนอุปกรณ์สัมผัสหรือจอเล็ก และ "สูง" บนจออื่น ถ้าเฟรมหลังการวาดช้ากว่า ~22 fps ต่อเนื่องจะลดระดับเอง
- การตั้งค่าเก็บใน `localStorage` คีย์ `citymanager.visual.v1` เฉพาะเบราว์เซอร์นั้น ถ้าอ่านไม่ได้จะใช้ค่าเริ่มต้น

## โลกรอบเมือง (4B)
- นอกกริด 24×24 เป็นภูมิประเทศตกแต่งแบบ height field (`src/scene-world.ts`): แผ่นดินใหญ่ทางตะวันตกพร้อมทางหลวงต่อจากประตูเมือง, เนินเขาและป่าทางเหนือ/ตะวันออก, หาดทรายและทะเลตื้นทางใต้ สร้างจาก hash คงที่ จึงเหมือนเดิมทุกครั้ง
- ทะเลเป็นผิวน้ำโปร่งแสงที่เห็นพื้นทรายใต้น้ำไล่ระดับความลึก สีน้ำตามท้องฟ้าและมืดลงตอนกลางคืน
- ต้นไม้ตกแต่งประมาณ 150 ต้นวางเฉพาะบนบก ไม่ขวางทางหลวง
- ภูมิประเทศนอกกริดสร้างไม่ได้ ไม่ถูก pick และไม่อยู่ในระบบจำลอง ทางหลวงไม่ใช่ส่วนของ road graph
- โซน R/C/I/F เป็นพื้นโปร่งแสงพร้อมขอบสีทึบ จางลงเมื่อมีอาคารแล้ว
- vertex color ทั้งพื้นโลกและท้องฟ้าแปลง sRGB → linear ก่อนส่งให้ shader เพื่อไม่ให้สีซีด

## ถนนและอาคาร (4C)
- ถนนใช้ tile ของ Kenney (ทางตรง ทางตัน หัวมุม สามแยก สี่แยกพร้อมทางม้าลาย ทางม้าลายกลางถนน) เลือกและหมุนจากเพื่อนบ้านถนนจริงของแต่ละแปลง ถนนที่ไม่เชื่อมประตูเมืองยังเป็นสีแดง ทางหลวงนอกเมืองใช้ tile เดียวกัน
- ไฟถนนตั้งบนทางเท้าของถนนตรงทั้งแนวนอนและแนวตั้ง ทุก 4 แปลง
- อาคารแยกชุดตามระดับ: บ้าน R1 ชั้นเดียว → R3 บ้านใหญ่, ร้านค้า → อาคารพาณิชย์ → ตึกสูงกระจก (C ระดับ 2–4), โรงงานเล็ก → ใหญ่ ระดับ 2 มีปล่อง ระดับ 3 มีถังวัตถุดิบเพิ่ม ตลาดระดับ 1 เป็นแผงใต้กันสาดกับร่ม ไม่ใช่อาคารร้านค้า
- ไม่สร้างตึกเกินระดับที่ระบบจำลองมี; รายการโมเดลและที่มาอยู่ใน [ASSETS.md](ASSETS.md)
- อุปกรณ์ที่ไม่มี GPU (SwiftShader, llvmpipe, WARP ฯลฯ) เริ่มที่คุณภาพต่ำเมื่อเลือก "อัตโนมัติ"

## ชีวิตในเมือง (4D)
- **ภาพตกแต่งเท่านั้น** ไม่มีรถหรือคนรายตัวในระบบจำลอง ตัวเลขทั้งหมดอ่านจากข้อมูลจริงของวันนั้นผ่าน `trafficPlan(city)` (`src/traffic-plan.ts` ฟังก์ชันล้วน ไม่เรียก RNG ของ sim ไม่แก้ `City` ไม่เข้าเซฟ)
- รถยนต์: 1 คันต่อการจัดสรรงานจริง (บ้านของครัวเรือน → ที่ทำงาน) รวมเจ้าของตลาดที่ทำงานเอง สูงสุด 40 คัน
- รถบรรทุก: 1 คันต่อรายการขนส่งของวันนั้น (ขายส่ง นำเข้า ส่งออก ซื้อขายพืชผล) วิ่งทางเดียวจนถึงปลายทาง สูงสุด 12 คัน การนำเข้า/ส่งออกวิ่งไปยังประตูเมือง
- คนเดิน: ตามผู้อยู่อาศัยของบ้านที่เชื่อมถนน ไม่เกิน 2 คนต่อบ้าน สูงสุด 60 คน
- ควัน: เฉพาะโรงงานที่ผลิตจริงวันนั้น (`agriculture.recipe-ready` และมีแรงงาน)
- วิ่งเฉพาะถนนที่เชื่อมประตูเมืองและเมื่อมีน้ำไฟ เส้นทางสั้นสุดแบบ BFS บนกริดถนน ขับเลนขวา คนเดินบนทางเท้า ไฟหน้ารถติดตอนกลางคืน
- หยุดเมื่อ Pause หรือซ่อนแท็บ ปิดในคุณภาพต่ำ (รวมเครื่องที่ไม่มี GPU) และปิดเองได้ในเมนูบรรยากาศ (`traffic` ใน `citymanager.visual.v1`)
- ตัวรถใช้กล่อง procedural ก่อน ถ้าจะเปลี่ยนเป็นโมเดล Kenney Car Kit ให้เพิ่มผ่าน `scripts/prepare-city-assets.mjs` ตามขั้นตอนใน [ASSETS.md](ASSETS.md)

## ข้อมูลบนแผนที่ (เฟส 5)
- **ชั้นข้อมูลตามเครื่องมือ** (`mapOverlay`, `src/map-overlay.ts`): ถนน → เชื่อม/ไม่เชื่อมประตูเมือง (`connectedRoads`, `access`), ฟาร์ม → ความอุดมสมบูรณ์ทั้งกริด เส้นแบ่ง 50%, บ้าน → บ้านว่าง/มีที่ว่าง/เต็ม (`homeOccupancy`, `housingCapacity`) และแปลงบ้านว่างที่พร้อม/ติดเงื่อนไข, พาณิชย์/โรงงาน → แปลงพร้อมเกิดหรือติดเงื่อนไขตาม `explainCell` ของ sim เอง แผ่นสีไม่รับแสง จึงอ่านได้ตอนกลางคืน คำอธิบายสีอยู่เหนือแถบเครื่องมือ
- **พรีวิวการวาง** (`previewPlacement`, `src/placement-preview.ts`): กรอบเขียว/แดงและป้ายราคาหรือเหตุผลก่อนกด ใช้กฎเดียวกับ `buildRoad` / `zoneCell` / `bulldoze` แบบอ่านอย่างเดียว test เทียบผลพรีวิวกับการกระทำจริงบนสำเนาเมือง ข้อยกเว้นเดียว: การรื้ออาคารที่กิจการยังจ่ายค่าจ้าง/ภาษีค้างไม่ได้ ซึ่งระบบจะปฏิเสธตอนกดจริง
- **ไอคอนปัญหาเหนืออาคาร** (`buildingIssues`): ไม่มีถนนเชื่อม, น้ำไฟไม่พร้อม, ไม่มีแรงงาน, ขาดวัตถุดิบ, ดินไม่พอ (แดง) และคลังเต็ม, ไม่มีผู้ซื้อ, ไม่มีสินค้า, บ้านว่าง (เหลือง) จาก `economicSignals()` และการเข้าพักจริง รายละเอียดเดียวกันยังอยู่ในการ์ดอาคาร ไอคอนจึงไม่ใช่แหล่งข้อมูลเดียว
- ชั้น HTML ไม่รับการคลิก (`pointer-events: none`) ปิดได้ในเมนูบรรยากาศ (`mapInfo`) คำนวณใหม่เมื่อผังเมืองเปลี่ยน หรือไม่เกินทุก 0.5 วินาทีตอนเวลาเดิน
- **อาคารที่ขาดถนนเชื่อมประตูเมืองดูซีด** (`access()` เป็นเท็จ) เพราะระบบจำลองระงับการจ้างงาน การซื้อขาย การผลิต และการเติบโตของอาคารนั้น ไฟหน้าต่างจึงดับด้วย
- **แอนิเมชันก่อสร้าง/อัปเกรด** (`src/build-events.ts`): อาคารใหม่โตขึ้นจากพื้นใน 0.7 วินาที อัปเกรดระดับเด้งขึ้นเล็กน้อย 0.5 วินาที ข้ามเมื่อโหลดเซฟหรือมีอาคารเปลี่ยนพร้อมกันเกิน 6 หลัง และข้ามเมื่อผู้ใช้ตั้ง `prefers-reduced-motion`

## โค้ด
- `src/atmosphere.ts`: ฟังก์ชันล้วน ไม่มี WebGL: นาฬิกา, ตำแหน่งดวงอาทิตย์, keyframe สีท้องฟ้า, ฤดูกาล, ฝน (`tests/atmosphere.test.ts`)
- `src/scene-atmosphere.ts`: แสงอาทิตย์/จันทร์ เงา, sky dome แบบ vertex color, fog, `CameraFrame`, วัสดุเรืองแสง
- `src/atmosphere-controls.ts`: เมนู การตั้งค่า การลดคุณภาพอัตโนมัติ
- `src/weather-overlay.ts`: ฝน
- `src/scene-world.ts`: ภูมิประเทศ ทะเล และจุดวางต้นไม้รอบเมือง
- `src/map-overlay.ts`, `src/placement-preview.ts`: ชั้นข้อมูล ไอคอนปัญหา และพรีวิวการวาง (`tests/map-overlay.test.ts`)
- `src/map-markers.ts`: ป้ายและไอคอนบนจอที่ตามกล้อง
- `src/traffic-plan.ts`: แผนรถ/คนเดิน/รถบรรทุก/ควัน และ BFS ถนน (`tests/traffic-plan.test.ts`)
- `src/scene-traffic.ts`: วาดและเคลื่อนไหวภาพตกแต่ง
- `src/road-tiles.ts`: เลือก tile ถนนและการหมุนแบบฟังก์ชันล้วน (`tests/road-tiles.test.ts`)
- QA อ่านสถานะได้จาก `window.cityManager.atmosphere()`
