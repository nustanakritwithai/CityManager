# การ์ดตามประเภทสถานที่

GUI รุ่นนี้ต่อจากเกษตร PR #12 เป็นการเปลี่ยนการแสดงผลเท่านั้น ไม่แก้ตัวจำลอง กติกาเศรษฐกิจ save v4, road graph, PlayCanvas หรือ backend ไม่ใช่ dashboard ห้าการ์ดถาวรบนฉาก ภาพรวมเมือง คู่มือ และเมนูเกมยังแยกจากข้อมูลสถานที่

ใช้แนวทางหัวการ์ด ไอคอน สีประจำประเภท และกลุ่มตัวเลขจากภาพอ้างอิงที่ผู้ใช้ส่ง ไม่คัดลอกภาพต้นฉบับ ตัวเลข GDP หรือระบบที่ไม่มีอยู่ ภายในใช้ธีม navy เดียวกันพร้อมเส้นแบ่งและสีเน้นต่างกัน ไอคอนใหม่เป็น SVG ที่เขียนเอง ไม่มี asset/dependency เพิ่ม

| บริบท | ข้อมูลที่ขึ้นก่อน | รายละเอียดที่เปิดต่อได้ |
|---|---|---|
| บ้าน | พักอยู่จริง/ความจุ และรายการครัวเรือน | ความจุว่าง ระดับ อายุ เงื่อนไขย้ายเข้า; แตะครัวเรือนเพื่อดูเงินและงานของครอบครัวนั้น |
| ครัวเรือน | สมาชิก แรงงาน ผู้พึ่งพิง เงินร่วม | งานลูกจ้างแยกตามกิจการ งานเจ้าของตลาด ความสามารถ การซื้อ และรายการบัญชีของครัวเรือน |
| ร้านค้า | สินค้าพร้อมขาย และฝั่งซื้อ/ขาย | ปริมาณ เงิน ราคาจากรายการจริง เงินสด กำไรตามกติกาเดิม และลูกจ้าง |
| ตลาดพืชผล | ล็อต ต้นทุน กำไรดำเนินงาน และแรงงานเจ้าของ | ซื้อ/ขายจากสต็อกเดียวกัน เงินกิจการแยกจากครัวเรือน เติมทุน/ถอนกำไรตามวงเงินจริง |
| โรงงาน | วัตถุดิบ → สูตร/กำลังแปรรูป → สินค้าสำเร็จรูป | ผลิตจริงวันนี้แยกจากศักยภาพจากแรงงาน/สต็อก ค่าใช้จ่าย เงิน และลูกจ้าง |
| ฟาร์ม | แปลงหนึ่งช่อง ความอุดมสมบูรณ์ และเก็บเกี่ยวจริง | กำลังต่อแรงงาน สต็อกพืชผล ต้นทุน แรงงาน และเงินกิจการ |

บ้านแสดงเฉพาะครัวเรือนที่อ้างอิงบ้านนั้น ไม่เรียกเงินของผู้อาศัยว่ามูลค่าหรือเงินเจ้าของบ้าน ครัวเรือนเป็นหน่วยเงินร่วมของสมาชิกหลายคน งานแสดงเป็นจำนวนแรงงาน/กลุ่มทักษะ ไม่สร้างชื่อหรือประวัติรายบุคคลขึ้นใหม่

## ความหมายของตัวเลข

- เงินสดคือยอดปัจจุบัน; เงินโอนเข้า/ออก/สุทธิเป็น flow ในช่วงไม่เกิน 30 วัน รวมวันต้นและปลาย ช่วงเริ่มต้นระบุแยก เงินเติมทุน/ถอนกำไรอาจอยู่ใน flow จึงไม่เรียกว่า P&L
- ช่วงข้อมูลของบ้านอ้างถึงครัวเรือนที่พักอยู่ตอนเลือก ไม่ย้อนสมมติว่าผู้พักปัจจุบันเคยอยู่ที่นี่ตลอดช่วง
- ราคาซื้อ/ขายเป็นค่าเฉลี่ยถ่วงน้ำหนักจากการจับคู่ physical journal กับเงินจริง ไม่ใช่ราคาประกาศหรือกราฟประวัติ หากจับคู่ไม่ได้ เกินขอบเขต หรือราคาเฉลี่ยไม่ลงตัวเป็นสตางค์ จะไม่สร้างราคาแทน โดยแสดงเหตุผลและยอดเงิน/ปริมาณที่ยืนยันได้
- คงกำไรของร้านค้าตามกติกาบัญชีต้นแบบเดิม ไม่เพิ่มต้นทุนสินค้าสำเร็จรูปแบบ accrual/COGS ใหม่ ตลาดพืชผลมีต้นทุนสต็อกและกำไรจากการขายตามระบบเกษตรเดิม
- จำนวนแปลงฟาร์มเป็นช่องกริดจริง ไม่แปลงเป็นตารางเมตรหรืออ้างว่ามีภูมิประเทศ/พื้นที่เกษตรขนาดจริงใหม่
- ค่าดิบเดิมยังอยู่ครบ รายการรองย้ายเข้า disclosure ที่เปิดด้วย pointer/keyboard ได้ ไม่ทำสำเนาค่า เงิน หรือสต็อก

`building-card-data.ts` เป็น projection แบบอ่านอย่างเดียว UI อ้างอิง ID ที่เลือก ล้างบริบทเมื่อเปลี่ยน/ลบสถานที่ และใช้ navigation, owner callbacks และ native-input guard เดิม ไม่มีคำขอ AI เพิ่มจากการเปิดการ์ด

## มือถือและการตรวจ

แผงเปิดสูงตามพื้นที่จอจริง รักษา Back/ปิดและ scroll เดิม คืนพื้นที่เมืองเมื่อปิด ไม่มี footer บันทึก/โหลดติดทุกการ์ด ข้อความหลักอย่างน้อย 14 หน่วยอ่าน ปุ่มสัมผัสอย่างน้อย 44 หน่วย และรองรับ layout 980 บน screen 390 โดยไม่ปิดการซูม

ผลตรวจและภาพจริงอยู่ [building-cards-preview](building-cards-preview/) รวม normal/fallback, การเลือกสลับ ข้อมูลไม่รั่ว ปุ่มเจ้าของกิจการ กล้อง การลบ เซฟ/โหลด และ regression เดิม การตรวจ S22 เป็น viewport/touch emulation ไม่ใช่โทรศัพท์จริง ยึด exact-head CI ใน PR ก่อนพิจารณา Merge/เผยแพร่
