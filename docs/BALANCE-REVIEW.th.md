# ขอบเขตการปรับสมดุล

เมืองใหม่ใช้เป้าหมายรุ่น 2: ระดับสุดท้ายต้องมีถนนเชื่อมประตูเมืองที่ให้บริการบ้านที่มีผู้อยู่อาศัยหรือกิจการที่มีคนทำงาน โดยทั้งสองต้องมีน้ำไฟ อย่างน้อย 18 ช่อง โดยต้องมีทั้งแนวนอนและแนวตั้งอย่างน้อยด้านละ 5 ช่องและไม่นับช่องถนนเดียวกันซ้ำ ถนนร้างและอาคารว่างไม่นับ ประชากร 60 คน การซื้อสินค้าร้าน 1,800 หน่วยใน 30 วัน การส่งสินค้าจากโรงงานในเมือง ไม่มีการนำเข้ารอบล่าสุด และเงินคลังเติบโตสามเดือน การซื้อจากร้านไม่ยืนยันแหล่งกำเนิดสินค้าเพราะสต็อกถูกรวมกัน เป้าหมายเป็นสถานะปัจจุบันที่เปลี่ยนกลับได้ ไม่ใช่รางวัลถาวร เซฟเก่าซึ่งไม่มีตัวบ่งชี้รุ่น 2 ยังใช้เกณฑ์เดิมเพื่อไม่ถอยความคืบหน้า

ต้นทุนบริการพื้นฐานคิดเดือนละ 50 บาทต่อคน จ่ายไม่เกินเงินที่มีหลังกำรองค่าจ้าง ไม่มีหนี้และยังไม่จำลองคุณภาพบริการ โหลดเซฟไม่คิดย้อนหลัง การทดสอบ seed 61025 ลดรายได้สุทธิต่อเดือนช่วงท้ายจากประมาณ 1,833 เป็น 433 บาท แต่ยังสะสมต่อ (69,780.54 บาทในวันที่ 3,600) จึงไม่ถือว่าแก้เงินล้นทั้งหมด

**อนุมัติให้ดำเนินการแล้ว แต่ยังไม่ได้ปล่อยจริง:** ระงับการโอนค่าโดยสารแท็กซี่เข้าคลังชั่วคราว เพราะจำนวนเที่ยวบนภาพไม่ใช่ข้อมูลผู้โดยสารและการชำระเงินจริง อู่และภาพรถยังทำงานและบันทึกได้ ยอดเงินและรายการค่าโดยสารเดิมไม่ถูกหักหรือแก้เมื่อโหลดเซฟ ส่วนการย่อประวัติทำงานตามปกติ ระบบทริปผู้โดยสารและการชำระเงินจริงยังไม่ได้พัฒนา ยังไม่มีระบบลงทุนใหม่ และยังไม่ได้ทดสอบใน browser

ทดสอบเฉพาะส่วนด้วย `node --experimental-strip-types --test --test-concurrency=1 tests/main-goal-network.test.ts tests/city-goals.test.ts tests/city-side-missions.test.ts tests/city-challenges.test.ts tests/guide.test.ts tests/municipal-services.test.ts` และ `npm run build`; ผลเปรียบเทียบเป็นซิม seed 61025 ไม่ใช่การรับประกันระยะเวลาเล่นของทุกเมือง

ตัวเลือกแท็กซี่ผ่านการทดสอบเฉพาะ `tests/taxi-save-fares.test.ts` 6 กรณี และชุด taxi/modal/municipal 26 กรณีก่อนเพิ่มกรณีไม่มีอุปสงค์; `npm run build` ผ่าน การจำลองเมือง seed 61025 ที่เปิดอู่ 3,600 วันได้ยอดคลังเท่ากันทั้งเมื่อรันและไม่รันภาพจราจร แต่ยังต้องมี browser QA ก่อนพิจารณาปล่อย

หน้าการเงินมีทางลัดเปิดเครื่องมือสร้างสวน น้ำ ไฟ และสถานศึกษาเมื่อระบบการศึกษาพร้อม โดยแสดงราคาจริง ค่าบำรุง และข้อจำกัดก่อนเลือก ผู้เล่นยังต้องเลือกแปลงเองและจ่ายเมื่อสร้างสำเร็จ สวนสร้างงานได้เมื่อมีผู้สมัครและงบค่าจ้าง แต่ไม่รับประกันตำแหน่งที่มีคนทำ และไม่มีโบนัสเศรษฐกิจหรือพื้นที่บริการจำลอง ทางลัดไม่ได้สร้างทุนโรงงานเอกชนหรือแก้เงินสะสมทั้งหมด

การทดลองสร้างสวนวันที่ 300 ใน seed 61025, 2026 และ 42 ใช้ค่าก่อสร้าง 1,000 บาทและค่าบำรุง 10 บาท/เดือน เทียบกับไม่สร้าง ยอดคลังวันที่ 720 ลดลง 1,140 บาทเท่ากันทั้งสาม seed มีตำแหน่งสวนที่มีงบแต่ยังไม่มีผู้สมัครในตัวอย่างนี้ ไม่ถือเป็นการรับประกันการจ้างงาน เดือนที่ลงทุนอาจทำให้เงื่อนไขคลังเติบโตสามเดือนเริ่มนับใหม่

การทดลองวิจัยแยกต่างหากลดภาษีกำไรกิจการจาก 20% เป็น 10% และเพิ่มโซนอุตสาหกรรมที่ต่อถนนเมื่อไม่มีแปลงว่าง พบว่าโรงงานแห่งที่สองมาเร็วขึ้น 12–30 วันในสาม seed แต่ทั้งสาม seed มีรายรับสุทธิติดลบ 67.30 บาทในเดือนวันที่ 180 เมื่อรวมค่าบริการปัจจุบัน การเปลี่ยนภาษีจริงยังไม่ได้ทำ เพราะต้องรองรับการตรวจสอบภาษีและเงินสำรองในประวัติเซฟเก่าและประเมินผลต่อเป้าหมายสามเดือนเพิ่มเติม
