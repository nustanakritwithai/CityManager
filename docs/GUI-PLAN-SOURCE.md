# ที่มาของแผน GUI และขอบเขตรอบนี้

[CityManager-GUI-Plan-TH.md](CityManager-GUI-Plan-TH.md) เป็นเอกสารออกแบบตามคำขอผู้ใช้ จัดทำจากแนวทางและภาพอ้างอิงที่ผู้ใช้ส่ง และรับเข้าจาก Library เมื่อ 24 ตุลาคม 2026 ไม่ใช่บันทึกภายในหรือหลักฐานว่าระบบทั้งหมดในแผนพัฒนาแล้ว

รอบนี้ส่งเฉพาะ GUI ภายในห้าเมนูเดิม: เงิน สินค้า กระเป๋าเงิน วิธีเล่น และสมมติฐาน พร้อมปุ่มกลับ การอ่านบนจอสัมผัส และการรักษาข้อมูลจริง แผนส่วนแดชบอร์ดเมือง การเชื่อมรายละเอียดครัวเรือน/บริษัท ประวัติกราฟ localization และการตรวจ screen reader เต็มรูปแบบเป็นงานถัดไป ไม่ได้รวมอยู่ในการรับรองรอบนี้

ใช้ข้อกำหนดความหมายหน่วยในแผนแก้ป้าย HUD ให้ระบุจำนวนครัวเรือนตามข้อมูลจริง โดยไม่สร้างประชากรรายบุคคล ตัวเลขเงินยังคงหน่วยแสดงเดิมของต้นแบบ (บาท/สตางค์) และจำนวนเต็มเดิม การตัดสินหน่วยเงินเชิงผลิตภัณฑ์และ metric dictionary แบบรวมทุกหน้าเป็นงานออกแบบถัดไป ไม่มีการแปลงยอดเงินหรือแก้กฎเศรษฐกิจในรอบนี้
