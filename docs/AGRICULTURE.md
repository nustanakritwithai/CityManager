# เกษตร ตลาด และวัตถุดิบ รุ่น 4 — รอตรวจแยกก่อนเผยแพร่

เพิ่มเพียงพืชผลหนึ่งชนิด ใช้เป็น input โรงงานหรือซื้อกินโดยตรงผ่านตลาดได้ สินค้าสำเร็จรูปของร้านค้าเดิมคงอยู่ ครัวเรือนต้องการหนึ่งตะกร้ารวมต่อวัน เลือกพืชสดหรือสินค้าร้านค้า ไม่ซื้อซ้ำสองช่องทาง ไม่มีแร่ เหมือง นม เครื่องมือ หนี้ หรือตลาดลงทุนในรุ่นนี้

## กติกาเกมที่เสนอและนำมาใช้

- Fertility 0–100 สร้างจาก seed แบบ `fertility-1` โดยไม่ใช้ RNG ของ simulation บันทึกและตรวจเทียบ canonical map ทุกครั้ง ฟาร์มต้องมีอย่างน้อย50% ถนน น้ำ ไฟ และแรงงานจริง พืชผลเกิดใหม่ได้ ไม่ใช่แหล่งแร่จำกัด
- F คือฟาร์มแปลงเล็ก หนึ่งแรงงาน เก็บได้ floor(24×fertility/100) ล็อตต่อวัน จำกัด96ล็อต T คือตลาดเล็ก หนึ่งเจ้าของลงแรง จำกัด48ล็อต โรงงานเก็บ input ไม่เกิน24ล็อต ใช้2ล็อตต่อแรงงานหนึ่งคนเพื่อผลิต8หน่วยสินค้าสำเร็จรูป
- แรงงานผลิตทำงานโรงงาน/ฟาร์มได้ แรงงานค้าปลีกทำงานร้านค้า/ตลาด ทักษะทั่วไปยืดหยุ่นได้ บทบาทรายได้ลูกจ้างและทำกิจการเองแยกจากกลุ่มทักษะเหล่านี้
- ราคาเสนอเป็นพารามิเตอร์เกม: ฟาร์มขายส่งตลาด1.50, ตลาดขายโรงงาน3, ฟาร์มขายตรงล็อตย่อยให้โรงงาน3.50เครดิตต่อล็อต ครัวเรือนซื้อพืชสดหนึ่งล็อตหรือสินค้าทั่วไปหนึ่งหน่วย8เครดิต ไม่ใช่ราคาหรือสูตรจริงจาก CSII
- โรงงานซื้อก่อนตลาดเติมสต็อก ตลาดขายให้โรงงานและครัวเรือนได้เฉพาะจำนวนที่มีตั้งแต่ต้นรอบ ทั้งสองกลุ่มหักสต็อกกองเดียวกัน สินค้าที่ตลาดเพิ่งซื้อจะขายได้วันถัดไป ไม่มีตลาดซื้อวนกันหรือรับประกันซื้อคืนจากภายนอก
- ใช้ช่องทางซื้อขายที่เชื่อมถึง gateway เดียวกันและลำดับ price/ID คงที่ ไม่มีรถรายคัน เวลาขนส่ง หรือการเรียก AI ทุก tick PR #6 เรื่องระยะทางอ่านประกอบแล้ว แต่ไม่ได้ Merge หรือนำโค้ดมารวม

## เงิน ทุน และต้นทุน

กิจการ I/C/F รับทุนเริ่ม3000เครดิตจากบัญชีนักลงทุนภายนอก `outside` ที่มีคู่รายการเงินจริง และจ่ายก่อสร้าง400เครดิต ตลาด T ใช้600เครดิตจากกระเป๋าครัวเรือนเจ้าของจริง จ่ายก่อสร้าง100 เหลือ500ในบัญชีกิจการ ไม่มีทุนภายนอกแอบเติมให้ตลาด

หนึ่งครัวเรือนมีตลาดเล็กได้หนึ่งแห่ง เจ้าของกันแรงงานทั่วไปหรือค้าปลีกหนึ่งคนจาก pool เดียวกับงานลูกจ้าง งานเก่าที่ถูกย้ายยังรักษาค่าจ้างที่ทำแล้ว เจ้าของไม่รับเงินเดือนสมมติ สมาชิกคนอื่นทำงานต่างกิจการต่อได้ เงินครัวเรือนกับเงินกิจการยังแยกบัญชี

ต้นทุนพืชผลใช้ weighted acquisition cost เป็นสตางค์จำนวนเต็ม ขายบางส่วนปัดลงและเก็บเศษกับสต็อกที่เหลือ ซื้อของเป็นสินทรัพย์คงคลัง ไม่เป็นกำไรหรือค่าใช้จ่ายทันที ตลาดรับรู้ยอดขายและต้นทุนเฉพาะส่วนที่ขายจริง พร้อมค่าเช่า30เครดิต/เดือน ไม่มีเงินเดือนเจ้าของ โรงงานลงต้นทุนวัตถุดิบเมื่อแปรรูป ไม่ได้เพิ่มระบบบัญชีสินทรัพย์สินค้าสำเร็จรูป/ค่าเสื่อม/หนี้เต็มรูปแบบในรุ่นนี้

ปุ่มเติมทุน/ถอนกำไร100เครดิตเป็นการโอนจริง ถอนกำไรได้ไม่เกินผลที่เกิดจริงหลังสำรองภาษี และต้องเหลือเงินหมุนเวียน200เครดิต ไม่กวาดยอดขายทั้งหมดกลับบ้าน การรื้อเขียน off สต็อกด้วยต้นทุนที่เหลือ ชำระสิทธิค่าจ้าง/ภาษีที่เกิด แล้วแยกคืนทุนกับแจกกำไร ไม่ลบกระเป๋าหรือ journal ประวัติ

## การย้ายเซฟและข้อจำกัด

อ่าน [นโยบายเซฟ](AGRICULTURE-SAVES.md) ตัวอ่าน v1/v2/v3 ตรวจตามกติกาเก่าก่อนแปลง คง ID เงิน แรงงาน ค่าแรงค้าง สินค้าสำเร็จรูป และประวัติเดิม เพิ่มพืชผลศูนย์โดยไม่มีการแจก input หรือเปลี่ยนสินค้าสำเร็จรูปเป็นวัตถุดิบ โรงงานเดิมหยุดผลิตเมื่อไม่มี input และแสดงเหตุผลจนผู้เล่นวางแหล่งผลิต/ตลาดจริง

เซฟใหม่ช่อง v4 แยกจาก v1–v3 มี backup ต้นฉบับแบบ immutable ก่อน Save เท่านั้น Load ไม่เขียน storage เมืองใหม่มีโซน F/T เริ่มต้นที่เข้าถึงถนนและมี fertility ใช้ได้ เมืองนำเข้าไม่มีอาคาร/โซนใหม่แอบเพิ่ม

หน้าสัญญาณ Typhoon คง contract เดิม โดยนับแรงงานเจ้าของรวมกับลูกจ้างอย่างไม่ซ้ำ `economicSignals()` เพิ่ม reason ID ปริมาณ หน่วย และ tick ของข้อจำกัด crop แบบอ่านอย่างเดียวสำหรับ adapter ระยะถัดไป ยังไม่ส่ง metric ที่ backend ไม่รองรับหรือเพิ่มคำขอผู้ให้บริการ

สี่บทบาทรายได้แบ่งพัฒนาแยก: ลูกจ้าง, ทำกิจการเอง, เจ้าของธุรกิจ/ผู้บริหาร, นักลงทุน ผู้บริหารที่เป็นลูกจ้างไม่ถือว่าเป็นเจ้าของโดยอัตโนมัติ รุ่นนี้เพิ่มเฉพาะตลาดที่ทำกิจการเอง ไม่รับประกันผลตอบแทน และไม่มีธุรกรรมเงินจริง
