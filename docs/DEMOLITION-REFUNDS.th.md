# เงินคืนเมื่อรื้อถอน

เมื่อรื้อสิ่งปลูกสร้างที่เมืองจ่าย คืนเงินเข้าคลัง **80% ของค่าก่อสร้างและอัปเกรดที่มีหลักฐานการจ่าย** ไม่มีค่ารื้อหักเพิ่มสำหรับสิ่งปลูกสร้างเทศบาล

- โรงไฟฟ้าและโรงสูบน้ำ: รวมค่าก่อสร้างกับค่าอัปเกรดที่จ่ายแล้วทุกระดับ
- สวนสาธารณะ: คืน 800 จากค่าก่อสร้าง 1,000
- โรงเรียนและมหาวิทยาลัย: รวมค่าก่อสร้างกับค่าขยายที่มีหลักฐาน
- ถนนที่สร้างด้วยรุ่นนี้: คืน 40 ต่อช่องที่เมืองจ่ายสร้าง 50 การลากผ่านถนนเดิมไม่จ่ายซ้ำและไม่เพิ่มสิทธิเงินคืน
- บ้าน ร้านค้า โรงงาน และฟาร์ม: ผู้ลงทุนเอกชนหรือกิจการเป็นผู้จ่าย จึงไม่คืนเงินเข้าคลังเมือง ค่ารื้อเดิม 20 และการสะสางค่าจ้าง ภาษี เงินเจ้าของ และทุนคงเหลือยังใช้กฎเดิม
- อู่แท็กซี่ อู่รถเมล์ และป้ายรถเมล์ในรุ่นปัจจุบันไม่มีค่าก่อสร้างที่จ่ายจริง จึงไม่มีเงินคืน
- ประตูเมืองและพื้นที่สงวนยังรื้อไม่ได้

ยอดคืนไม่รวมค่าบำรุง ค่าจ้าง ค่าน้ำไฟ หรือเงินทุนหมุนเวียน ดูยอดเงินคืนและค่ารื้อได้ในการ์ดสถานที่ก่อนเลือกเครื่องมือรื้อถอน

## เซฟเก่า

ไม่เปลี่ยนยอดเงินหรือสร้างรายการเงินคืนตอนโหลดเซฟ โรงน้ำไฟและสวนใช้รายการก่อสร้าง/อัปเกรดเดิมที่เก็บไว้ โรงเรียนที่มีประวัติการจ่ายครบใช้ยอดเดิมได้เช่นกัน

เซฟถนนเก่าบันทึกค่าก่อสร้างเป็นยอดรวมหลายช่อง จึงพิสูจน์ไม่ได้ว่าช่องที่ยังอยู่จ่ายเท่าใด เซฟโรงเรียนบางรุ่นอาจย่อประวัติและไม่เหลือรายละเอียดค่าก่อสร้าง/ขยาย ระบบไม่สมมติว่าราคาปัจจุบันคือราคาที่จ่ายในอดีต: คืนเฉพาะส่วนที่ยังพิสูจน์ได้และแจ้งในการ์ดว่าประวัติไม่ครบ ถนนเก่าที่ไม่มีหลักฐานแยกช่องจึงคืน 0; ถ้าสร้างใหม่หลังรื้อ การจ่ายใหม่นั้นมีหลักฐานและคืน 80% ได้

## บัญชีและความปลอดภัย

เงินคืนโอนจากบัญชีค่าก่อสร้างหรือบัญชีงานถนนกลับเข้าคลัง ไม่สร้างเงินใหม่จากบัญชีภายนอก จำนวนเงินเป็นสตางค์จำนวนเต็ม คืนครั้งเดียวเมื่อรื้อสำเร็จ การกดซ้ำบนช่องว่างไม่ให้เงินเพิ่ม และการสร้างใหม่ต้องจ่ายใหม่ การโหลด บันทึก และย่อประวัติต้องรักษาหลักฐานที่จำเป็นสำหรับสิ่งปลูกสร้างที่ยังอยู่และรายการคืนเงินที่ยังต้องตรวจสอบ
