# แก้วงจรงานใหม่กับการย้ายเข้า

รุ่นนี้แก้เมืองที่มีบ้านว่างแต่ไม่มีตำแหน่งงานเพิ่ม ไม่เปลี่ยนตลาดพาณิชย์ระดับ 1 เป็นร้านค้าสำเร็จรูป และไม่เพิ่มประชากร เงิน หรือวัตถุดิบเพื่อข้ามข้อจำกัด

## หลักฐานและสาเหตุ

ภาพที่ผู้เล่นส่งแสดงประชากร 10 คน แรงงาน 8 คน งาน 8 ตำแหน่ง และไม่มีคนว่างงาน ส่วนภาพอีกรอบแสดงบ้านรองรับ 12 ครัวเรือน/48 คน แต่พักจริงเพียง 6 ครัวเรือน/10 คน ภาพเป็นคนละวันจำลอง จึงไม่ถือว่าเป็น snapshot เดียวกัน และยังไม่มีไฟล์เซฟจริงของผู้เล่น

การจำลองต้นฉบับ seed 61025 พบรูปแบบเดียวกัน: วันที่ประมาณ 120–600 ยังมีประชากร 10 คนและงาน 8 ตำแหน่ง แม้มีบ้านว่างและเพิ่มถนน/โซนที่ใช้ได้ โรงงานระดับ 3 ใช้แรงงานครบ 6 คนและมีกำไร ฟาร์มและตลาดมีพืชผลคงคลัง สินค้าสำเร็จรูปเป็นศูนย์เพราะผลิตแล้วขายส่งออกภายในวัน ไม่ใช่หลักฐานว่าหยุดผลิต

กติกาเดิมกำหนดว่าโรงงานเพิ่มต้องมีคนว่างงาน ขณะที่การย้ายเข้าต้องมีงานว่างที่จ่ายค่าจ้างได้ ทั้งสองเงื่อนไขรอกันเองเมื่อแรงงานเต็ม โรงงานเดิมยังติดเพดานระดับ 3 การรวม C เป็นตลาดระดับ 1 ลดเส้นทางเพิ่มงานร้านค้า แต่ไม่ใช่ต้นเหตุเพียงอย่างเดียว: กติกาก่อนรวมหมวดก็สามารถติดวงจรนี้ได้

## การลงทุนเปิดงานจริง

โรงงานแรกยังใช้ทุนภายนอกที่มีรายการบัญชีตามกติกาเริ่มเมืองเดิม หากไม่มีโรงงานเหลือเลยยังใช้นโยบายเริ่มอุตสาหกรรมเดิมได้ เพื่อไม่ปิดทางกู้เมืองหลังรื้อโรงงานสุดท้าย ส่วนการขยายขณะที่ยังมีโรงงานอยู่ต้องใช้เงินสดของกิจการที่ดำเนินงานจริง ไม่ใช้ทุนภายนอกแจกให้โครงการขยาย

ผู้ลงทุนต้องเชื่อมถนน น้ำ/ไฟพร้อม มีคนทำงานและกำไรตามเงื่อนไข มีพื้นที่อุตสาหกรรมที่เข้าถึงได้ และไม่มีตำแหน่งว่างที่ยังรอการจ้างจำนวนมาก ต้องมีที่พักรองรับการย้ายเข้าและพืชผลจริงสำหรับเริ่มดำเนินงานด้วย ไม่จองหรือคัดลอกสต็อกขึ้นใหม่

ทุนเริ่มต้น **300,000 สตางค์ (3,000 เครดิต)** เป็นพารามิเตอร์เกม ใช้ระดับเดียวกับทุนเริ่มกิจการเดิม ก่อนโอนต้องกันค่าจ้างที่ทำงานแล้ว ภาษีจากผลดำเนินงานที่เกิดขึ้น ค่าเช่า 10,000 สตางค์ และเงินหมุนเวียน 20,000 สตางค์ไว้ ผู้ลงทุนที่ผ่านเงื่อนไขเลือกตาม ID คงที่ การประเมินก่อสร้างยังเกิดทุกสามวันตามกติกาเดิม

เงินโอนจากกระเป๋ากิจการผู้ลงทุนไปยังกิจการใหม่เป็นรายการคู่ จากนั้นกิจการใหม่จ่ายค่าก่อสร้าง 40,000 สตางค์ตามเดิม ทุนไม่ใช่ยอดขายของผู้รับหรือค่าใช้จ่ายดำเนินงานของผู้ลงทุน การจ้าง ค่าจ้าง การซื้อวัตถุดิบ การผลิต และการย้ายเข้ายังต้องเกิดจริงในวันต่อไป ไม่มีคนทำงานหรือสินค้าผลิตทันทีจากการเพิ่มอาคาร

`fundedBy` ระบุที่มาทุนและสิทธิในเงินคงเหลือของโครงการ เมื่อปิดกิจการต้องสะสางค่าจ้าง ภาษี และสต็อกก่อน เงินที่เหลือจึงคืนบัญชีผู้ลงทุน บัญชีเดิมคงอยู่แม้กิจการผู้ลงทุนถูกปิดไปแล้ว เงินที่รับภายหลังยังอยู่ในบัญชีที่เก็บไว้และมีรายการย้อนตรวจได้ ไม่ลบภาระหรือส่งเงินส่วนนี้ออกนอกระบบโดยเงียบ ๆ ยังไม่มีระบบไล่แบ่งเงินผ่านกลุ่มบริษัทที่เลิกกิจการหลายชั้นอัตโนมัติ

นี่เป็นหลักฐานทุนสำหรับโครงการขยาย ไม่ใช่ระบบบริหารกลุ่มบริษัท การกู้ยืม ดอกเบี้ย เงินปันผล หรือการประเมินมูลค่าหุ้น กำไรในแผงกิจการยังหมายถึงผลดำเนินงานตามกติกาต้นแบบ ไม่ใช่งบการเงินรวมของกลุ่มบริษัท

## ข้อจำกัดจริงยังหยุดการเติบโตได้

เงินไม่พอ วัตถุดิบขาด ถนนขาด น้ำ/ไฟไม่พร้อม บ้านไม่มีที่ว่าง หรือไม่มีโซนที่เหมาะสม ยังเป็นเหตุให้รอได้ หน้าข้อมูลต้องบอกเหตุและเงินที่มีจริง ไม่แสดงแถบเติบโตสมมติ

สต็อกพืชผลใช้เริ่มกิจการได้ แต่ไม่ได้รับรองว่าฟาร์มเดิมเลี้ยงโรงงานใหม่ได้ตลอด ผู้เล่นยังต้องจัดโซนฟาร์มที่อุดมสมบูรณ์และเชื่อมถนนเมื่อความต้องการสูงขึ้น การทดสอบแยกกรณีที่มีพื้นที่/อุปทานครบออกจากกรณีขาดของจริง ไม่บังคับให้ทุกเมืองโตได้ไม่สิ้นสุด

## เซฟและการตรวจรับ

เซฟใหม่ใช้ `6 / growth-1` ใน `citymanager.save.v6` พร้อมอ่าน v1–v5 ผ่านตัวตรวจของรุ่นเดิม เก็บ bytes และ backup เก่าแยกกัน การโหลดไม่เดินเวลา ไม่เปลี่ยนยอดเงิน สินค้า ID เจ้าของ งาน หรือค่าจ้างเดิม และไม่สร้างโครงการลงทุนย้อนหลังให้เซฟที่ยังไม่เคยมี

ชุดทดสอบต้องครอบคลุมเมืองใหม่ระยะยาว เมือง v5 ที่ติดอยู่วันที่ 388 การโอนทุนและเงินสำรอง การเพิ่มงาน/ย้ายเข้าที่มีเงื่อนไขจริง กรณีขาดทุน/เงิน/ของ/ถนน การปิดกิจการทั้งผู้รับทุนและผู้ลงทุน การโหลดซ้ำ และ GUI บนขนาดจอมือถือ ผลจาก commit และ CI จริงระบุใน PR ของรุ่นนี้

ไม่เปลี่ยนสัญญา snapshot/report ของ Typhoon และไม่เพิ่มคำขอ API ต่อวันจำลอง ไม่มี backend หรือ credentials ใหม่ การตรวจมือถือเป็น viewport/touch emulation จนกว่าจะมีผลทดสอบเครื่องจริงแยกต่างหาก
