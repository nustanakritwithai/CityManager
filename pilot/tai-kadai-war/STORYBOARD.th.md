# สตอรีบอร์ด: สงครามและการอพยพของไทกะได

งานทดสอบแรกของสกิล `map-story-motion` (แทนเรื่องแม่น้ำโขงใน [แผนรอบตัวอย่าง](../../docs/NEWS-MOTION-SKILL-PILOT.th.md))
สถานะ: **รอผู้ใช้ยืนยัน (จุดยืนยันที่ 1)** ยังไม่เรนเดอร์

- เนื้อหาต้นทาง: บทความ "สงครามและการอพยพของไทกะได" โดย กชกร นันทพันธ์ (22 ต.ค. 2569)
- ธีม: `neon-history` ดาวเทียมโทนมืด เส้นเรืองแสง · แนวตั้ง 1080×1920 · 30fps · ซับอย่างเดียว
- ความยาวรวม ≈ 3 นาที 20 วินาที แบ่งเป็น 3 ตอน (ข้อ 5)
- คอลัมน์ "อ้างอิง" ชี้ไปที่ส่วนของบทความต้นทาง: §1 การลงมาของฮั่น, §2 ราชวงศ์ถัง, §3 หนงจื้อเกา, §4 แผนที่รูป 2, §5 สรุป, §N หมายเหตุ ตัวเลขในวงเล็บคือแหล่งในรายการหนังสืออ้างอิงของบทความ

## 1. ตัวละครบนแผนที่ (สี)
| ฝ่าย | สี | ใช้กับ |
|---|---|---|
| ไป่เยว่ / คนใต้ / ไทกะได | เหลืองทอง | พื้นที่ใต้แยงซี, หมุดเมืองไท |
| จิ๋น / ฮั่น / ถัง / ซ่ง (ราชสำนักจีน) | แดง | ลูกศรทัพ, หมุดเมืองที่ราชสำนักยึด |
| หนานเจา / ต้าหลี่ | ม่วง | พื้นที่ยูนนาน |
| จ้วง (หนง, หวง) | ฟ้า | หมุดฝั่งตะวันออกแม่น้ำแดง, ลูกศรลุกฮือ |
| แม่น้ำ | ฟ้าอ่อนบาง | แยงซี หวย แดง โขง อู |

## 5. รูปแบบการตัด
- **ค่าเริ่มต้น**: 3 ตอน (≈ 70 / 75 / 80 วิ) แต่ละตอนเปิดด้วยหัวข้อ "ตอนที่ N" และจบด้วยการ์ดแหล่งที่มาย่อ เหมาะกับ Reels/TikTok
- **ทางเลือก**: คลิปยาวเดียว ≈ 3:20 สำหรับ Facebook/YouTube
- รอบทดสอบเรนเดอร์ **ตอนที่ 2 ก่อน** เพราะใช้เทคนิคมากที่สุด (หมุดหลายจุด สถิติ พื้นที่หนานเจา ลูกศรทัพ คำพูดอ้างอิง) แล้วค่อยทำตอน 1 และ 3

## 7. เรื่องที่ต้องให้ผู้ใช้ตัดสิน
1. **สิทธิ์ในเนื้อหา**: ผู้ใช้คือ กชกร นันทพันธ์ หรือได้รับอนุญาตให้ทำเป็นคลิปแล้ว? (คลิปจะใส่เครดิตผู้เขียนเสมอ)
2. **แผนที่รูป 1 และ 2** มาจากหนังสือที่มีลิขสิทธิ์ ผมจะ **ไม่ใช้ภาพต้นฉบับในคลิป** แต่วาดหมุดใหม่บนแผนที่ดาวเทียมและเขียนว่า "ดัดแปลงจาก…" ตกลงไหม หรือผู้ใช้มีสิทธิ์ใช้ภาพต้นฉบับ (จะแทรกเป็นการ์ดภาพ "รูป 1/รูป 2" ได้)
3. **ตัวเลขผู้เสียชีวิต** (20,000 / 60,000 / 150,000 / 30,000) แสดงเป็นตัวเลขบนการ์ด ไม่มีภาพความรุนแรง ตกลงไหม
4. **ตัดเป็น 3 ตอน** หรือคลิปยาวเดียว
5. **พิกัดที่ติด ⚠️/❌** ในข้อ 6
6. คำบรรยายในซับย่อจากต้นฉบับเพื่อให้อ่านทันใน 2 บรรทัด ผู้ใช้ตรวจว่าความหมายไม่เพี้ยน โดยเฉพาะคำว่า **"อาจ" "น่าจะ" "มีส่วน" "แม้ไม่ใช่ทั้งหมด"** ที่ผมคงไว้ตามต้นฉบับ
